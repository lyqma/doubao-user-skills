# 01 · 中国·长安 —— 重檐歇山顶 + 唐式灯楼

> 序列：01。文明：大唐。特征色：唐红、鎏金。

- 文字：“长安”
- 特征色：唐红、鎏金

## 专属顶部造型
```
跨街装置中央顶部设置重檐歇山顶。歇山顶不是实体屋顶，不是金属板。
屋顶轮廓由不锈钢杆件形成真实三维空间骨架，表面覆盖连续1cm×1cm不锈钢方格网。
屋顶内部完全透空，可以透过网格看到后方道路和天空。
双层檐口由不锈钢圆杆弯折成型，飞檐起翘，檐角轻盈上挑。
檐下设置多层斗拱，由不锈钢杆件形成真实三维结构，内部采用1cm方格网，镂空透视。
斗拱层层出挑，承托双层檐口。屋顶正脊两端设鸱吻剪影，由金属杆件与方格网构成，镂空。
歇山顶两侧设置唐式灯楼。灯楼为四边形或六边形楼台式，由不锈钢杆件形成骨架，
表面覆1cm方格网，楼台分层设围栏与镂空窗，内部完全透空。
灯楼顶设宝顶，为金属镂空构件，不是实体。
屋顶与灯楼可局部染唐红、鎏金，但金属丝本身不发光，颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置唐式斗拱。斗拱由不锈钢杆件形成真实三维结构，内部采用1cm方格网，镂空透视。
外立面设置直棂窗。窗棂由不锈钢杆件形成，内部采用1cm方格网，透空。
外立面设置唐草纹、几何纹、联珠纹、缠枝莲纹，均由金属细丝编织，镂空、透视，
不形成实体雕花板。
局部可染唐红、鎏金、朱砂，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：唐式灯楼内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。灯楼各层悬挂六角宫灯，宫灯为金属网格编织成六角造型的镂空灯体，
内部透出暖黄光2700K。宫灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰左右对称布置。
灯饰布局为唐式灯楼宫灯悬挂式。
```

字体端正大气，贴合大唐文化气韵，不生成杂乱字体。
