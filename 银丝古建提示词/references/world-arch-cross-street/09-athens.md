# 09 · 希腊·雅典 —— 帕特农柱廊 + 三角楣雕塑群

> 序列：09。文明：古希腊。特征色：雅典米白、爱琴海蓝。

## 专属辨识造型
- 顶部：帕特农神庙柱廊 + 三角楣雕塑群
- 装饰：科林斯柱头、女像柱、饰带浮雕
- 灯饰：希腊陶灯、橄榄枝灯
- 文字：“雅典”
- 特征色：雅典米白、爱琴海蓝

## 结构差异化声明
```
本装置结构不与01长安、02敦煌、03喀什、04撒马尔罕、05波斯、06巴格达、
07大马士革、08伊斯坦布尔、10罗马重复。
不设重檐歇山顶与斗拱飞檐、不设唐式灯楼、不设飞天与三兔藻井与莲花穹顶、
不设连续尖拱廊与洋葱小穹顶、不设雷吉斯坦肋纹蓝色穹顶、不设双牛柱头与镂空圆盘、
不设伊什塔尔门式城门与塔楼、不设倭马亚连拱廊与宣礼塔、
不设圣索菲亚大穹顶与细长宣礼塔、不设斗兽场多层连续拱券与罗马柱式。
顶部以帕特农神庙式柱廊与三角楣为唯一核心，外立面以多立克/科林斯柱式、
希腊回纹、橄榄枝纹为主题，灯饰不采用两侧灯楼形式，改为柱廊内透光、
三角楣下方悬挂希腊陶灯与柱头橄榄枝灯。
整体结构为中央柱廊+三角楣+柱廊透光式布局。
```

## 专属顶部造型
```
跨街装置中央顶部设置帕特农神庙式柱廊。柱廊由多根希腊式圆柱组成，
柱身由不锈钢杆件形成圆柱形空间骨架，内部采用连续1cm×1cm不锈钢方格网，镂空、透视、真实三维结构。
柱身竖向凹槽由金属杆件形成，凹槽之间为密集方格网。
柱头为科林斯式，茛苕叶由金属细丝编织成翻卷叶片轮廓，叶片内部留空；
柱头两侧设爱奥尼式双卷涡纹；柱头颈部设蛋箭纹与珠链纹。
柱廊顶部连接檐部与三角楣。三角楣不是实体山花，不是金属板。
三角楣轮廓由不锈钢杆件形成真实三维空间骨架，表面覆盖连续1cm×1cm不锈钢方格网。
三角楣内部完全透空，可以透过网格看到后方道路和天空。
三角楣内设置希腊神话人物群像镂空雕塑：雅典娜、波塞冬、神话战斗场景、祭祀行列。
人物由不锈钢杆件形成三维轮廓，内部覆1cm方格网，前后错落、有进深、有立体层次，
不是平板浮雕，不是实体雕塑。人物衣褶用金属细丝编织表现。
三角楣三个角设置独立镂空角饰，由金属杆件与方格网构成，内部透空。
柱廊上方设置连续饰带浮雕，由连续镂空金属网格条带构成，
人物以金属杆件勾勒轮廓，内部网格填充，形成连续叙事感。
饰带中交替设置排档间饰方板，方板内为单场景金属网格人物浮雕，方板之间为三槽线饰带。
柱廊内部设置装饰性女像柱，女像柱不是落地结构柱，不增加立柱数量，
仅作为柱廊内镂空雕塑构件。女性人物由不锈钢杆件形成三维人体轮廓骨架，
表面覆1cm方格网，人体内部透空，衣褶用金属细丝编织，头部承接篮形柱头。
三角楣可局部染大理石白、爱琴海蓝、铜金色光点，但金属丝本身不发光，
颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置帕特农神庙式柱廊。柱身由不锈钢杆件形成圆柱形骨架，内部采用1cm方格网。
柱头为科林斯式，茛苕叶由金属细丝编织成翻卷叶片轮廓，叶片内部留空；
柱头两侧设爱奥尼式双卷涡纹；柱头颈部设蛋箭纹与珠链纹。
外立面设置希腊回纹、橄榄枝纹、棕榈叶饰、忍冬纹、几何纹、联珠纹、缠枝莲纹，
均由金属细丝编织，镂空、透视，不形成实体雕花板。
外立面设置希腊神话人物剪影、雅典娜雕像轮廓、波塞冬雕像轮廓、神话战斗场景，
均由金属杆件和密集方格网构成，镂空、透视、真实三维结构，不形成实体浮雕板。
局部可染大理石白、爱琴海蓝、铜金，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：柱廊内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。三角楣下方悬挂希腊陶灯，陶灯为金属网格编织成古希腊陶器造型的镂空灯体，
内部透出暖黄光2700K。柱头处设置橄榄枝灯，橄榄枝灯为金属网格编织成橄榄枝造型的镂空灯体，
内部透出暖黄光。
陶灯与橄榄枝灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰左右对称布置，左右两侧灯位、数量、高度、间距完全镜像对称。
灯饰布局为柱廊内透光与三角楣悬挂陶灯结合式。
```

## 专属汉字标识
```
装置正中央悬挂金属镂空汉字标识“雅典”。
采用规整毛笔字体，字体笔画由不锈钢细丝方格网与金属杆件构成，镂空、透视、与银丝古建材质统一。
字体端正大气，贴合古希腊文化气韵，不生成杂乱字体。
```
