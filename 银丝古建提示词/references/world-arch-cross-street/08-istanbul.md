# 08 · 土耳其·伊斯坦布尔 —— 圣索菲亚大穹顶 + 细长宣礼塔

> 序列：08。文明：拜占庭/土耳其。特征色：土耳其浅金。

## 专属辨识造型
- 顶部：圣索菲亚大穹顶 + 半穹顶 + 细长宣礼塔
- 装饰：拱窗、马赛克纹、伊斯兰几何纹
- 灯饰：新月灯、金灯
- 文字：“伊斯坦布尔”
- 特征色：土耳其浅金

## 结构差异化声明
```
本装置结构不与01长安、02敦煌、03喀什、04撒马尔罕、05波斯、06巴格达、
07大马士革、09雅典、10罗马重复。
不设重檐歇山顶与斗拱飞檐、不设唐式灯楼、不设飞天与三兔藻井与莲花穹顶、
不设连续尖拱廊与洋葱小穹顶、不设雷吉斯坦肋纹蓝色穹顶、不设双牛柱头与镂空圆盘、
不设伊什塔尔门式城门与塔楼、不设倭马亚连拱廊与方形宣礼塔、
不设帕特农柱廊与三角楣、不设斗兽场多层连续拱券与罗马柱式。
顶部以圣索菲亚式大穹顶、半穹顶和细长宣礼塔为唯一核心，外立面以拱窗、马赛克纹、
伊斯兰几何纹为主题，灯饰不采用两侧灯楼形式，改为穹顶内透光、
宣礼塔顶部悬挂新月灯、拱券下方悬挂土耳其金灯。
整体结构为中央大穹顶+半穹顶+细长宣礼塔式布局。
```

## 专属顶部造型
```
跨街装置中央顶部设置大型圣索菲亚式大穹顶。穹顶不是实体穹顶，不是金属板，不是实心雕塑。
穹顶轮廓由不锈钢杆件形成真实三维空间曲线骨架，表面覆盖连续1cm×1cm不锈钢方格网。
穹顶内部完全透空，可以透过网格看到后方道路和天空。
大穹顶下方连接多个半穹顶和拱券，形成圣索菲亚式层叠空间轮廓。
半穹顶与拱券同样由不锈钢杆件与密集方格网构成，镂空、透视、真实三维结构。
穹顶两侧设置细长宣礼塔。宣礼塔不是实体塔，不是金属板。
塔身由不锈钢杆件形成真实三维空间骨架，表面覆盖连续密集的1cm×1cm不锈钢方格网。
塔身呈伊斯兰宣礼塔细长圆柱轮廓，带有层叠阳台和顶部尖顶。
塔顶新月标志为金属镂空构件，不是实体，不是发光体。塔身内部完全透空。
穹顶网格可局部染土耳其新月金、铜金色光点，但金属丝本身不发光，
颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置圣索菲亚式拱窗。拱窗由不锈钢杆件形成拱形轮廓，内部采用1cm方格网，透空。
外立面设置伊斯坦布尔特有的马赛克纹、伊斯兰几何纹、联珠纹、缠枝莲纹、阿拉伯书法纹样，
均由金属细丝编织，镂空、透视，不形成实体雕花板。
局部可染土耳其新月金、铜金、朱砂，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：大穹顶内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。宣礼塔顶部悬挂新月灯，新月灯为金属网格编织成新月造型的镂空灯体，
内部透出暖黄光2700K。拱券下方悬挂土耳其金灯，金灯为金属网格编织成镂空灯体，
具有土耳其传统铜器造型，内部透出暖黄光。
新月灯与金灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰布局为穹顶内透光与新月灯悬挂式结合。
```

## 专属汉字标识
```
装置正中央悬挂金属镂空汉字标识“伊斯坦布尔”。
采用规整毛笔字体，字体笔画由不锈钢细丝方格网与金属杆件构成，镂空、透视、与银丝古建材质统一。
字体端正大气，贴合土耳其文化气韵，不生成杂乱字体。
```
