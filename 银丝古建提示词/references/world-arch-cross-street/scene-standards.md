# 场景基底标准（所有跨街装置统一）

## 唯一场景基底

```
真实道路实景合成，严格以真实的敦煌沙州南路商业街夜景作为唯一现场环境基础。
真实商业街道路、沥青路面、路沿石、人行道、绿化带、两侧商铺、仿古建筑、行道树、
暖黄色灯笼、少量真实车辆和行人均自然保留。不得改变原有道路空间关系。
```

## 场景硬性约束

1. **唯一性**：必须以敦煌沙州南路商业街夜景为唯一现场环境，不得替换成其它街道/广场/景区。
2. **原生保留**：沥青路面、路沿石、人行道、绿化带、两侧商铺、仿古建筑、行道树、暖黄灯笼、少量车辆与行人全部自然保留。
3. **空间关系不变**：不得改变原有道路空间关系（车道宽度、人行道位置、建筑轮廓线）。
4. **单组装置**：画面中仅生成一组、且只有一组本主题装置，禁止第二组、重复装置或复制装置。

## 街道环境用词（正面，可复用）

```
真实商业街、沥青路面、路沿石、人行道、绿化带、
两侧仿古商铺、仿古建筑、行道树、暖黄色灯笼、
少量真实车辆、散步行人、暖黄招牌光
```

## 街道环境负面（禁止）

```
改变道路空间、扩建广场、移除商铺、空无一人的街道、
异国街道背景、现代玻璃幕墙商业街、景区实景大门、
额外第二组装置、复制装置、重复装置
```
