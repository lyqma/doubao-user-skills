# 灯光标准（所有跨街装置统一）

## 灯光核心原则

```
主体不锈钢保持自然银灰。银丝本身不发光。
LED隐藏在结构内部，仅作背后辅助照明。
冰蓝白光仅作为弱环境光。
各座专属灯具采用2700K暖黄色光。
各座特征色仅作为局部环境光点缀。
禁止霓虹线、光纤、发光轮廓。夜景通透亮。
```

## 分层灯光模型

| 层次 | 光源 | 色温/颜色 | 强度 | 作用 |
|------|------|-----------|------|------|
| 主体 | 不锈钢自然银灰 | 环境反射 | — | 保持金属本色 |
| 内透光 | 结构内LED | 柔和冰蓝白 | 弱 | 从1cm方格网中溢出 |
| 主灯具 | 各座专属灯 | 2700K暖黄 | 中 | 宫灯/铜灯/陶灯等 |
| 特征色 | 局部点缀 | 各座专属 | 极弱 | 环境光点缀 |

## 灯光负面（禁止）

```
霓虹线、光纤、激光线、发光轮廓、银丝发光、网格发光、
过强蓝光、大面积实体色块、自发光金属、外露LED灯带
```

## 夜景通透亮要求

- 灯光以冰蓝白内透为主，局部点缀各国特征色
- 宫灯与灯笼统一2700K暖黄
- 银丝不发光，光从网格背后透出，形成暗部金属轮廓
