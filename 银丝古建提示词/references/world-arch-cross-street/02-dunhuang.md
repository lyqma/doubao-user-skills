# 02 · 中国·敦煌 —— 三兔藻井 + 莲花穹顶 + 飞天

> 序列：02。文明：敦煌。特征色：敦煌鎏金。

## 专属辨识造型
- 顶部：三兔藻井 + 莲花穹顶
- 装饰：飞天反弹琵琶、飘带
- 灯饰：莲花灯
- 文字：“敦煌”
- 特征色：敦煌鎏金

## 结构差异化声明
```
本装置结构不与01长安、03喀什、04撒马尔罕、05波斯、06巴格达、
07大马士革、08伊斯坦布尔、09雅典、10罗马重复。
不设重檐歇山顶与斗拱飞檐、不设唐式灯楼、不设连续尖拱廊与洋葱小穹顶、
不设雷吉斯坦肋纹蓝色穹顶、不设双牛柱头与镂空圆盘、不设伊什塔尔门式城门与塔楼、
不设倭马亚连拱廊与宣礼塔、不设圣索菲亚大穹顶与细长宣礼塔、
不设帕特农柱廊与三角楣、不设斗兽场多层连续拱券与罗马柱式。
顶部以三兔藻井与莲花穹顶为唯一核心，外立面以飞天、莲花、忍冬纹为主题，
灯饰不采用两侧灯楼形式，改为莲花穹顶内透光与莲花灯悬挂式。
整体结构为飞天藻井式布局。
```

## 专属顶部造型
```
跨街装置中央顶部设置莲花穹顶。穹顶不是实体穹顶，不是金属板。
穹顶轮廓由不锈钢杆件形成真实三维空间曲线骨架，表面覆盖连续1cm×1cm不锈钢方格网。
穹顶内部完全透空，可以透过网格看到后方道路和天空。
穹顶顶部设置三兔藻井。藻井由层层内收的不锈钢杆件与方格网构成，
中央为三只首尾相衔的兔子镂空剪影，由金属杆件勾勒轮廓，内部覆1cm方格网，镂空透视。
藻井四周环绕莲花瓣，由金属杆件与方格网构成镂空花瓣，层层展开。
穹顶与藻井可局部染敦煌鎏金，但金属丝本身不发光，颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置飞天反弹琵琶。飞天人物由不锈钢杆件形成三维轮廓，内部覆1cm方格网，
人体内部透空，衣带飘舞。飞天手持琵琶，琵琶为镂空网格造型。
外立面设置飘带。飘带由金属细丝编织成流动条带，镂空、透视，随风舞动。
外立面设置莲花纹、忍冬纹、几何纹、联珠纹、缠枝莲纹，均由金属细丝编织，镂空、透视，
不形成实体雕花板。
局部可染敦煌鎏金、朱砂，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：莲花穹顶内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。穹顶下方悬挂莲花灯，莲花灯为金属网格编织成莲花造型的镂空灯体，
内部透出暖黄光2700K。莲花灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰左右对称布置。
灯饰布局为莲花穹顶内透光与莲花灯悬挂式。
```

## 专属汉字标识
```
装置正中央悬挂金属镂空汉字标识“敦煌”。
采用规整毛笔字体，字体笔画由不锈钢细丝方格网与金属杆件构成，镂空、透视、与银丝古建材质统一。
字体端正大气，贴合敦煌文化气韵，不生成杂乱字体。
```
