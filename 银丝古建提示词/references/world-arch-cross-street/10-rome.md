# 10 · 罗马 —— 斗兽场多层连续拱券 + 罗马柱式

> 序列：10。文明：古罗马。特征色：罗马红铜。
> 注意：文字标识只有“罗马”，不得出现SPQR、罗马数字、拉丁文、英文或其他文字。

- 文字：“罗马”
- 特征色：罗马红铜

## 专属顶部造型
```
跨街装置中央顶部设置罗马斗兽场式多层连续拱券。拱券不是实体建筑，不是金属板，不是实心雕塑。
多层拱券轮廓由不锈钢杆件形成真实三维空间骨架，表面覆盖连续1cm×1cm不锈钢方格网。
拱券内部完全透空，可以透过网格看到后方道路和天空。
拱券呈典型罗马斗兽场多层连续拱廊构图，分为上下两层或三层，
每层由多个连续半圆拱组成，拱与拱之间以罗马壁柱式杆件分隔。
拱券边缘以精细不锈钢杆件勾勒罗马线脚、蛋箭纹、珠链纹、月桂纹，
纹样同样由金属杆件和密集方格网构成，镂空、透视、真实三维结构。
多层拱券顶部设置罗马式檐口，檐口上方设置四马战车镂空雕塑。
四马与战车由不锈钢杆件形成三维轮廓，内部覆1cm方格网，镂空、透视、有进深。
拱券中央设置母狼育婴镂空雕塑。母狼与婴孩由不锈钢杆件形成三维轮廓，
内部覆1cm方格网，镂空、透视、有立体层次，不是实体雕塑，不是平板浮雕。
拱券表面设置罗马历史叙事浮雕带。浮雕人物由不锈钢杆件形成三维轮廓，
内部覆1cm方格网，前后错落、有进深、有立体层次，不是平板浮雕，不是实体雕塑。
浮雕内容表现罗马军团、凯旋仪式、神话场景。
拱券可局部染罗马红、铜金、大理石白，但金属丝本身不发光，
颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置罗马斗兽场式多层连续拱券。拱券由不锈钢圆杆弯折成型，表面覆1cm方格网，
拱门内部完全透空。
外立面设置罗马多立克式、科林斯式或混合式壁柱。柱身由不锈钢杆件形成圆柱形骨架，
内部采用1cm方格网。柱头为科林斯式或混合式，茛苕叶由金属细丝编织成翻卷叶片轮廓，
叶片内部留空；柱头两侧设罗马式双卷涡纹；柱头颈部设蛋箭纹与珠链纹。
外立面设置罗马历史叙事浮雕带、月桂冠纹、罗马回纹、几何纹、联珠纹、缠枝莲纹，
均由金属细丝编织，镂空、透视，不形成实体雕花板。
外立面设置罗马母狼育婴雕塑轮廓、四马战车剪影，均由金属杆件和密集方格网构成，
镂空、透视、真实三维结构，不形成实体浮雕板。
局部可染罗马红、铜金、大理石白，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：多层拱券内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。拱券下方悬挂罗马铜灯，铜灯为金属网格编织成古罗马铜器造型的镂空灯体，
内部透出暖黄光2700K。柱头处设置月桂灯，月桂灯为金属网格编织成月桂冠造型的镂空灯体，
内部透出暖黄光。
铜灯与月桂灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰左右对称布置，左右两侧灯位、数量、高度、间距完全镜像对称。
灯饰布局为多层拱券内透光与罗马铜灯悬挂式。
```
