## 二、通用框架（每座装置都必须遵守）

每座装置生成时，提示词必须按以下顺序组装：

1. **场景基底**（固定）：真实道路实景合成，敦煌沙州南路商业街夜景
2. **唯一性声明**：画面中仅生成一组、且只有一组本主题装置
3. **空间尺寸落位**（最高优先级）
4. **银丝古建核心构造**
5. **银丝网格**
6. **结构差异化声明**（不与 01–10 其它装置重复）
7. **该座顶部造型**
8. **该座外立面装饰**
9. **该座灯饰设计**
10. **该座汉字标识**
11. **灯光**
12. **摄影**

钢结构负责承重和空间轮廓，细丝方格网负责主体填充和连续镂空表皮。
所有造型直接由金属结构构成，内部保持空腔，不存在实体墙体、实体板材。
可以透过网格看到后方道路、商铺、天空和环境。
