# 07 · 大马士革 —— 倭马亚连拱廊 + 宣礼塔

> 序列：07。文明：阿拉伯（倭马亚）。特征色：大马士革铜金。

## 专属辨识造型
- 顶部：倭马亚清真寺连拱廊 + 细长宣礼塔
- 装饰：阿拉伯书法、伊斯兰几何纹
- 灯饰：星月灯、铜灯
- 文字：“大马士革”
- 特征色：大马士革铜金

## 结构差异化声明
```
本装置结构不与01长安、02敦煌、03喀什、04撒马尔罕、05波斯、06巴格达、
08伊斯坦布尔、09雅典、10罗马重复。
不设重檐歇山顶与斗拱飞檐、不设唐式灯楼、不设飞天与三兔藻井与莲花穹顶、
不设连续尖拱廊与洋葱小穹顶、不设雷吉斯坦肋纹蓝色穹顶、不设双牛柱头与镂空圆盘、
不设伊什塔尔门式城门与塔楼、不设圣索菲亚大穹顶与细长宣礼塔、
不设帕特农柱廊与三角楣、不设斗兽场多层连续拱券与罗马柱式。
顶部以倭马亚清真寺连拱廊与细长宣礼塔为唯一核心，外立面以连拱、阿拉伯书法、
伊斯兰几何纹为主题，灯饰不采用两侧灯楼形式，改为拱廊内透光、
宣礼塔顶部悬挂伊斯兰星月灯与拱券下方悬挂大马士革铜灯。
整体结构为中央连拱廊+宣礼塔+拱廊透光式布局。
```

## 专属顶部造型
```
跨街装置中央顶部设置倭马亚清真寺式连拱廊。连拱廊由多个连续半圆拱组成，
拱券由不锈钢圆杆形成真实三维空间骨架，表面覆盖连续1cm×1cm不锈钢方格网。
连拱廊内部完全透空，可以透过网格看到后方道路和天空。
拱与拱之间以细长壁柱式杆件分隔，柱身由不锈钢杆件形成竖向骨架，内部采用1cm方格网。
连拱廊两侧设置细长宣礼塔。宣礼塔由不锈钢杆件形成方形或圆柱形塔身骨架，
表面覆盖1cm方格网，塔身设层叠阳台与顶部尖顶。
塔顶设伊斯兰新月标志，为金属镂空构件，不是实体，不是发光体。
宣礼塔内部完全透空，可以透过网格看到后方道路和天空。
拱廊与宣礼塔可局部染大马士革金、铜金，但金属丝本身不发光，
颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置倭马亚清真寺式连拱券。拱券由不锈钢圆杆弯折成型，表面覆1cm方格网，
拱门内部完全透空。
外立面设置大马士革特有的伊斯兰几何纹、联珠纹、缠枝莲纹、阿拉伯书法纹样、藤蔓纹，
均由金属细丝编织，镂空、透视，不形成实体雕花板。
阿拉伯书法以金属细丝方格网构成，镂空、透视，与银丝古建材质统一。
局部可染大马士革金、铜金、朱砂，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：连拱廊内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。宣礼塔顶部悬挂伊斯兰星月灯，星月灯为金属网格编织成星月造型的镂空灯体，
内部透出暖黄光2700K。拱券下方悬挂大马士革铜灯，铜灯为金属网格编织成镂空灯体，
具有大马士革传统铜器造型，内部透出暖黄光。
星月灯与铜灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰布局为拱廊内透光与宣礼塔星月灯悬挂式结合。
```

## 专属汉字标识
```
装置正中央悬挂金属镂空汉字标识“大马士革”。
采用规整毛笔字体，字体笔画由不锈钢细丝方格网与金属杆件构成，镂空、透视、与银丝古建材质统一。
字体端正大气，贴合大马士革文化气韵，不生成杂乱字体。
```
