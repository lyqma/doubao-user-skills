# 银丝古建材质标准 · 跨街装置专版

> 本文件定义"跨街银丝古建装置"的材质体系。与单栋亭台版（见 material-standards.md）同源，
> 但针对"跨街装置 + 世界建筑造型 + 镂空透视"强化了结构与网格要求。

## 一、材质公式（最高优先级，不可修改）

```
银丝古建（跨街装置） =
真实钢结构骨架（承重 + 空间轮廓）
+ 精细不锈钢杆件（造型轮廓）
+ 高密度 1cm×1cm 不锈钢细丝方格网（主体填充 + 连续镂空表皮）
+ 真实金属连接节点（焊接/螺栓）
```

## 二、结构分解

| 构件类别 | 材质表现 | 说明 |
|----------|----------|------|
| 结构骨架 | 真实钢结构 | 负责承重和空间轮廓 |
| 杆件 | 精细不锈钢杆件 | 形成三维空间骨架 |
| 主体填充 | 1cm×1cm不锈钢细丝方格网 | 连续镂空表皮 |
| 连接节点 | 真实金属连接节点 | 焊接/螺栓，真实可建造 |

## 三、银丝网格规则

```
所有构件均采用连续、均匀、密集、正交排列的不锈钢方格网。
规则正方形，约1cm×1cm，金属丝直径1–2mm。
近景清晰可见密集方格网，远景识别完整的建筑造型。
```

### 网格正确表现
- 连续、均匀、密集、正交排列
- 规则正方形网格，约1cm×1cm
- 金属丝直径1–2mm
- 近景可见密集方格，远景可识别整体造型
- 镂空、透视，可看到后方道路/商铺/天空/环境

### 网格错误表现（禁止）
- 只有钢架没有网格、只有轮廓没有网格
- 网格只出现在局部
- 稀疏金属线、大孔网格、随机网格、不规则网格
- 二维线条、二维网格、白色线稿、描边、贴图网格

## 四、空腔与透视要求

```
所有造型直接由金属结构构成，内部保持空腔，不存在实体墙体、实体板材。
可以透过网格看到后方道路、商铺、天空和环境。
```

## 五、材质统一性

- 所有构件颜色一致：银灰色哑光不锈钢（或极细亮银）
- 允许随环境光产生暖/冷反射，但不改变银灰底色
- 金属丝本身不发光，光从网格背后透出

## 六、禁止材质（跨街专版）

```
实体建筑、实体墙体、实体瓦片、实心屋顶、实体斗拱、仿木结构、
银色实体古建筑、银色油漆、塑料、玻璃、树脂、铁艺、
实心雕塑、实心板材、实体雕花板、金属板、
只有钢架没有网格、只有轮廓没有网格、网格只出现在局部、
稀疏金属线、大孔网格、随机网格、不规则网格、
二维线条、二维网格、白色线稿、描边、贴图网格
```
