# 04 · 中亚·撒马尔罕 —— 雷吉斯坦肋纹蓝色穹顶

> 序列：04。文明：中亚。特征色：撒马尔罕钴蓝。

## 专属辨识造型
- 顶部：雷吉斯坦肋纹蓝色穹顶
- 装饰：尖拱券、星纹
- 灯饰：石榴灯
- 文字：“撒马尔罕”
- 特征色：撒马尔罕钴蓝

## 专属顶部造型
```
跨街装置中央顶部设置雷吉斯坦肋纹蓝色穹顶。穹顶不是实体穹顶，不是金属板。
穹顶轮廓由不锈钢杆件形成真实三维空间曲线骨架，表面覆盖连续1cm×1cm不锈钢方格网。
穹顶外表面以金属细丝编织成竖向肋纹，肋纹呈放射状或网格状排列，镂空、透视。
穹顶内部完全透空，可以透过网格看到后方道路和天空。
穹顶底部设鼓座，鼓座由不锈钢杆件形成柱状骨架，内部采用1cm方格网，镂空。
穹顶顶部设尖顶饰，为金属镂空构件，不是实体，不是发光体。
穹顶下方设置尖拱券，尖拱券由不锈钢圆杆弯折成型，表面覆1cm方格网，拱门内部透空。
穹顶与尖拱券可局部染撒马尔罕钴蓝，但金属丝本身不发光，
颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置尖拱券。拱券由不锈钢圆杆弯折成型，表面覆1cm方格网，拱门内部完全透空。
外立面设置星纹、伊斯兰几何纹、联珠纹、缠枝莲纹，均由金属细丝编织，镂空、透视，
不形成实体雕花板。
局部可染撒马尔罕钴蓝、铜金，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：雷吉斯坦穹顶内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。穹顶下方或尖拱券下悬挂石榴灯，石榴灯为金属网格编织成石榴造型的镂空灯体，
内部透出暖黄光2700K。石榴灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰左右对称布置。
灯饰布局为穹顶内透光与石榴灯悬挂式。
```

## 专属汉字标识
```
装置正中央悬挂金属镂空汉字标识“撒马尔罕”。
采用规整毛笔字体，字体笔画由不锈钢细丝方格网与金属杆件构成，镂空、透视、与银丝古建材质统一。
字体端正大气，贴合中亚文化气韵，不生成杂乱字体。
```
