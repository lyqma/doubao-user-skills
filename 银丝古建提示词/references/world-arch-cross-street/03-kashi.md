# 03 · 西域·喀什 —— 连续尖拱廊 + 洋葱小穹顶

> 序列：03。文明：伊斯兰（喀什）。特征色：喀什土黄。

## 专属辨识造型
- 顶部：连续尖拱廊 + 洋葱小穹顶
- 装饰：都塔尔琴、伊斯兰几何纹
- 灯饰：铜灯
- 文字：“喀什”
- 特征色：喀什土黄

## 结构差异化声明
```
本装置结构不与01长安、02敦煌、04撒马尔罕、05波斯、06巴格达、
07大马士革、08伊斯坦布尔、09雅典、10罗马重复。
不设重檐歇山顶与斗拱飞檐、不设唐式灯楼、不设飞天与三兔藻井与莲花穹顶、
不设雷吉斯坦肋纹蓝色穹顶、不设双牛柱头与镂空圆盘、不设伊什塔尔门式城门与塔楼、
不设倭马亚连拱廊与宣礼塔、不设圣索菲亚大穹顶与细长宣礼塔、
不设帕特农柱廊与三角楣、不设斗兽场多层连续拱券与罗马柱式。
顶部以连续尖拱廊与洋葱小穹顶为唯一核心，外立面以伊斯兰几何纹、藤蔓纹为主题，
灯饰不采用两侧灯楼形式，改为尖拱廊内透光与铜灯悬挂式。
整体结构为连续尖拱廊式布局。
```

## 专属顶部造型
```
跨街装置中央顶部设置连续尖拱廊。尖拱廊由多个连续尖拱组成，
拱券由不锈钢圆杆形成真实三维空间骨架，表面覆盖连续1cm×1cm不锈钢方格网。
尖拱廊内部完全透空，可以透过网格看到后方道路和天空。
拱与拱之间以细长壁柱式杆件分隔，柱身由不锈钢杆件形成竖向骨架，内部采用1cm方格网。
连续尖拱廊顶部设置洋葱小穹顶。小穹顶轮廓由不锈钢杆件形成三维空间曲线骨架，
表面覆盖1cm方格网，内部透空。穹顶底部设小鼓座，由金属杆件与方格网构成，镂空。
穹顶尖端设金属镂空装饰，不是实体，不是发光体。
尖拱廊与穹顶可局部染喀什土黄，但金属丝本身不发光，颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置连续尖拱券。拱券由不锈钢圆杆弯折成型，表面覆1cm方格网，拱门内部完全透空。
外立面设置都塔尔琴。琴身由不锈钢杆件形成轮廓，内部覆1cm方格网，镂空透视，
琴颈细长，琴腹呈梨形。
外立面设置伊斯兰几何纹、联珠纹、藤蔓纹、缠枝莲纹，均由金属细丝编织，镂空、透视，
不形成实体雕花板。
局部可染喀什土黄、朱砂，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：尖拱廊内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。拱券下方悬挂铜灯，铜灯为金属网格编织成传统铜器造型的镂空灯体，
内部透出暖黄光2700K。铜灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰左右对称布置。
灯饰布局为尖拱廊内透光与铜灯悬挂式。
```

## 专属汉字标识
```
装置正中央悬挂金属镂空汉字标识“喀什”。
采用规整毛笔字体，字体笔画由不锈钢细丝方格网与金属杆件构成，镂空、透视、与银丝古建材质统一。
字体端正大气，贴合西域文化气韵，不生成杂乱字体。
```
