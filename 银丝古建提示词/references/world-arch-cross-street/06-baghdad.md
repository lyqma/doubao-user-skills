# 06 · 两河·巴格达 —— 巴比伦伊什塔尔门

> 序列：06。文明：巴比伦。特征色：巴比伦藏蓝。

## 专属辨识造型
- 顶部：巴比伦伊什塔尔门式城门 + 塔楼
- 装饰：蓝色琉璃城门、狮子浮雕
- 灯饰：蓝灯
- 文字：“巴格达”
- 特征色：巴比伦藏蓝

## 结构差异化声明
```
本装置结构不与01长安、02敦煌、03喀什、04撒马尔罕、05波斯、
07大马士革、08伊斯坦布尔、09雅典、10罗马重复。
不设重檐歇山顶与斗拱飞檐、不设唐式灯楼、不设飞天与三兔藻井与莲花穹顶、
不设连续尖拱廊与洋葱小穹顶、不设雷吉斯坦肋纹蓝色穹顶、不设双牛柱头与镂空圆盘、
不设倭马亚连拱廊与宣礼塔、不设圣索菲亚大穹顶与细长宣礼塔、
不设帕特农柱廊与三角楣、不设斗兽场多层连续拱券与罗马柱式。
顶部以巴比伦伊什塔尔门式城门与塔楼为唯一核心，外立面以蓝色琉璃纹、狮子浮雕为主题，
灯饰不采用两侧灯楼形式，改为城门内透光与蓝灯悬挂式。
整体结构为城门塔楼式布局。
```

## 专属顶部造型
```
跨街装置中央顶部设置巴比伦伊什塔尔门式城门。城门不是实体城门，不是金属板。
城门轮廓由不锈钢杆件形成真实三维空间骨架，表面覆盖连续1cm×1cm不锈钢方格网。
城门为典型巴比伦拱形门洞构图，门洞上方设多层拱券与檐部，逐层内收。
城门两侧设置方形塔楼。塔楼由不锈钢杆件形成方形柱状骨架，表面覆1cm方格网，
塔楼分多层，每层设雉堞式镂空垛口，塔身内部完全透空。
塔楼顶部设锥形顶饰，为金属镂空构件，不是实体，不是发光体。
城门与塔楼表面以蓝色琉璃纹为主题，由金属细丝编织成蓝色调的方格纹、联珠纹、几何纹，
镂空、透视。城门口两侧设置狮子浮雕，狮子由不锈钢杆件形成三维轮廓，
内部覆1cm方格网，镂空、透视、有立体层次，不是实体浮雕，不是平板浮雕。
城门与塔楼可局部染巴比伦藏蓝，但金属丝本身不发光，
颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置巴比伦式拱券。拱券由不锈钢圆杆弯折成型，表面覆1cm方格网，拱门内部完全透空。
外立面设置蓝色琉璃纹、几何纹、联珠纹、缠枝莲纹，均由金属细丝编织，镂空、透视，
不形成实体雕花板。
外立面设置狮子浮雕剪影，由不锈钢杆件和密集方格网构成，镂空、透视、真实三维结构。
局部可染巴比伦藏蓝、铜金，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：城门内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。城门下方或塔楼处悬挂蓝灯，蓝灯为金属网格编织成方形或球形镂空灯体，
内部透出暖黄光2700K。蓝灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰左右对称布置。
灯饰布局为城门内透光与蓝灯悬挂式。
```

## 专属汉字标识
```
装置正中央悬挂金属镂空汉字标识“巴格达”。
采用规整毛笔字体，字体笔画由不锈钢细丝方格网与金属杆件构成，镂空、透视、与银丝古建材质统一。
字体端正大气，贴合两河文化气韵，不生成杂乱字体。
```
