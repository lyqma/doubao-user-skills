## 航拍版差异段

将上述"摄影师站在第一座建筑前低机位仰拍"替换为：

```
无人机航拍视角，高空斜俯视，全景横向长幅。
无人机从第一座“中国·长安”银丝古建装置正上方或后方约60-100米高度，
倾斜向下拍摄，镜头朝向街道远方消失点。……
航拍视角下，两侧立柱沿人行道整齐排列，不占用机动车道，道路中央完全空旷。
```

并在负面追加：
```
人视视角，地面视角，摄影师站在建筑前，平视，无航拍感，无人机不在高空，俯视角度错误。
```
