# 05 · 波斯·伊朗 —— 双牛柱头 + 波斯地毯镂空圆盘

> 序列：05。文明：波斯。特征色：波斯青釉。

## 专属辨识造型
- 顶部/装饰：双牛柱头 + 波斯地毯镂空圆盘
- 灯饰：波斯铜灯
- 文字：“波斯”
- 特征色：波斯青釉

## 结构差异化声明
```
本装置结构不与01长安、02敦煌、03喀什、04撒马尔罕、06巴格达、
07大马士革、08伊斯坦布尔、09雅典、10罗马重复。
不设重檐歇山顶与斗拱飞檐、不设唐式灯楼、不设飞天与三兔藻井与莲花穹顶、
不设连续尖拱廊与洋葱小穹顶、不设雷吉斯坦肋纹蓝色穹顶、不设伊什塔尔门式城门与塔楼、
不设倭马亚连拱廊与宣礼塔、不设圣索菲亚大穹顶与细长宣礼塔、
不设帕特农柱廊与三角楣、不设斗兽场多层连续拱券与罗马柱式。
顶部与装饰以双牛柱头与波斯地毯镂空圆盘为唯一核心，外立面以波斯纹样为主题，
灯饰不采用两侧灯楼形式，改为圆盘内透光与波斯铜灯悬挂式。
整体结构为双牛柱头式布局。
```

## 专属顶部造型
```
跨街装置顶部设置双牛柱头。柱头由不锈钢杆件形成双牛造型的镂空雕塑，
双牛为背对背相向的牛形，由金属杆件勾勒轮廓，内部覆1cm方格网，镂空、透视、有立体层次。
双牛柱头下方为柱身，柱身由不锈钢杆件形成圆柱形骨架，内部采用1cm方格网，镂空。
柱头与柱身不是实体雕塑，不是金属板。
柱头上方承托横梁与檐部，横梁由不锈钢杆件与方格网构成，镂空透视。
装置中央悬挂波斯地毯镂空圆盘。圆盘由不锈钢杆件形成圆形轮廓，
内部以金属细丝编织波斯地毯式几何花纹，镂空、透视，花纹呈辐射状或对称排列。
圆盘不是实体板材，不是实体雕花板，内部完全透空。
双牛柱头与圆盘可局部染波斯青釉，但金属丝本身不发光，
颜色仅作为局部环境光或金属构件局部颜色。
```

## 专属外立面装饰
```
外立面设置波斯纹样。以波斯地毯式几何纹、联珠纹、藤蔓纹、缠枝莲纹为主题，
均由金属细丝编织，镂空、透视，不形成实体雕花板。
外立面设置波斯柱式。柱身由不锈钢杆件形成圆柱形骨架，内部采用1cm方格网。
柱头为双牛造型或波斯式柱头，由金属杆件与方格网构成，镂空透视。
局部可染波斯青釉、蓝釉光点，但仅作为金属构件局部颜色。
禁止翅膀、翼板、翼状装饰。
```

## 专属灯饰
```
本装置灯饰与主体结构融合：波斯地毯圆盘内部设置柔和冰蓝白透光，光线从1cm方格网中溢出，
银丝不发光。圆盘下方或柱头处悬挂波斯铜灯，铜灯为金属网格编织成波斯铜器造型的镂空灯体，
内部透出暖黄光2700K。波斯铜灯间距约3至4米，排列整齐，不突破2.5米进深限制。
灯饰左右对称布置。
灯饰布局为圆盘内透光与波斯铜灯悬挂式。
```

## 专属汉字标识
```
装置正中央悬挂金属镂空汉字标识“波斯”。
采用规整毛笔字体，字体笔画由不锈钢细丝方格网与金属杆件构成，镂空、透视、与银丝古建材质统一。
字体端正大气，贴合波斯文化气韵，不生成杂乱字体。
```
