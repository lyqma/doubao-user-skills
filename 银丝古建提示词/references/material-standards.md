# 银丝古建 — 材质标准详解

## 一、材质公式

```
银丝古建 = 40×40mm方管钢结构骨架 + 1mm不锈钢钢丝1cm×1cm密集方格网 + 银灰色哑光亮银不锈钢
```

---

## 二、结构分解

### 立柱（承重构件）
| 属性 | 规格 |
|------|------|
| 材质 | 实体不锈钢方管 |
| 截面 | 40×40mm |
| 厚度 | 真实钢材厚度（非空心贴图） |
| 表面 | 银灰色哑光亮银不锈钢，细腻拉丝 |
| 节点 | 真实焊接痕迹可见 |

### 非立柱构件（所有装饰性/围护构件）
| 属性 | 规格 |
|------|------|
| 材质 | 1mm不锈钢钢丝编织 |
| 网格 | 1cm×1cm 密集方格网 |
| 构成 | 大量交叉钢丝，非几根线 |
| 效果 | 镂空结构，阳光可穿透，背景可透过网格可见 |

### 整体材质统一性
- 所有构件颜色一致：银灰色哑光亮银不锈钢
- 表面质感一致：细腻拉丝 + 真实金属反射
- 允许随环境光产生暖色/冷色反射变化，但不改变银灰底色

---

## 三、金属真实性要求

### ✅ 正确表现
```
- 根据环境光产生自然高光、柔和反射和局部明暗变化
- 保留真实钢材轻微拉丝纹理
- 微小表面不均匀性
- 真实焊接痕迹（焊缝凸出、热影响区变色）
- 真实结构连接细节（螺栓、焊接节点）
- 阳光穿过网格在下方投射密集网格阴影
```

### ❌ 错误表现
```
- 像塑料的质感
- 像铬镜面的高反射
- 像银漆的平面涂层
- 像CG材质的完美平滑
- 发光线条效果
- 透明贴图感
```

---

## 四、光影交互规则

| 场景 | 光影表现 |
|------|----------|
| 日光直射 | 网格投射密集几何阴影，金属表面有明确高光点 |
| 阴天柔光 | 整体均匀漫反射，金属表面柔和渐变色差 |
| 夜景内透光 | 暖色光从网格内部透出，外部轮廓有环境反射 |
| 暴雨天气 | 雨滴附着钢丝表面，反射冷冽环境光 |

---

## 五、颜色规则

- **主体色**：银灰色哑光亮银不锈钢（恒定）
- **允许**：环境光产生的暖/冷色调反射变化
- **禁止**：红色/黄色/金色覆盖主体材质（装饰色彩仅作为点缀）

---

## 六、建筑构件映射表

| 传统古建构件 | 银丝古建对应表现 |
|-------------|----------------|
| 木柱 | 40×40mm实体不锈钢方管 |
| 木梁 | 1cm×1cm钢丝网镂空梁 |
| 斗拱 | 钢丝网编织斗拱造型 |
| 瓦片屋面 | 钢丝网屋面轮廓 + 网格镂空 |
| 墙体 | 钢丝网镂空围护 |
| 栏杆 | 钢丝网栏杆 + 方管立柱 |
| 门窗 | 方管框架 + 钢丝网填充 |
