# H3 提示词模板（MiniMax H3 专用）

H3 的提示词不是散文，是"音画时间线控制表"：3 个固定字段 + 5 种模式开头句。字段名必须保留英文，字段里的内容可以用中文。

## 三字段骨架（顺序不能乱）

```
integrated_multimodal_description:  [Shot 1] ... [Shot 2] At 00:04.000, ...
overall_soundscape:                 全片环境声/动作声，1–4 句一段
non_diegetic_music:                 观众专属配乐，无则写 N/A
```

| 字段 | 装什么 | 禁什么 |
|---|---|---|
| integrated_multimodal_description | 画面、动作、镜头、对白、同步音效 | 情绪形容词、背景故事 |
| overall_soundscape | 环境声+动作声：雨、脚步、衣物、呼吸 | 对白、配乐（重复会打架） |
| non_diegetic_music | 乐器+速度+强弱变化 | 抽象情绪词；剧中收音机音乐 |

## 五种模式开头句

| 模式 | 开头必须写（第一行，空一行再写字段） |
|---|---|
| T2VA 文生视频 | 无，直接三字段 |
| I2VA 首帧 | `For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.` |
| FL2VA 首尾帧 | `How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark; Picture 2 (from Shot N) aligns with the 12.00-second mark of the target video.`（尾帧时间=实际时长，两位小数） |
| L2VA 尾帧 | `How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the 12.00-second mark of the target video.` |
| Ref2VA 全参考 | 六段式：subject_definitions → summary → retention_analysis → detailed_description → overall_soundscape → non_diegetic_music；素材用 <Subject N>/<Picture N>/<Video N>/<Audio N> 标签并固定复用 |

## 12 秒时间轴模板（黄金结构）

H3 支持 4–15 秒。12 秒建议 **3–4 镜、每镜 3–4 秒**。

```
[Shot 1]（0–3s，不写时间戳）风格+景别+主体+环境+钩子
[Shot 2] At 00:03.000（3–6s）动作发展+对白+运镜1
[Shot 3] At 00:06.000（6–9s）冲突/转折+运镜2+音效卡点
[Shot 4] At 00:09.000（9–12s）定格/金句/文字卡+音乐收束
```

- 时长预算速查：4–6s→1–2镜；7–10s→2–3镜；11–15s→3–5镜；单镜不低于 1.5s。
- 时间戳严格递增、精确到毫秒：`At 00:04.000`。
- 高潮/金句/标题放在第 8–12 秒。

## 对白与说话人

```
The baker with a calm voice (S1) says: <d>[Chinese] 第一炉出炉了。</d>
```

- 说话人固定编号 (S1)/(S2)；多镜复用同一编号；不发声的角色不编号。
- `<d>` 外写身份/动作/语气，`<d>` 内只放 `[语言] 台词原文`，一个字不改。
- 旁白：写 `says in an off-screen voiceover` 并紧跟 `while his lips remain completely closed`，否则人物会对旁白对口型。
- 台词跨切镜用 `<scenetrans>` 标衔接点并写"声音跨切镜连续"；结尾被截断用 `<cutoff>`。

## 屏幕文字

- 可见文字（招牌/标题/UI/字幕）用英文双引号括原文：`A red neon sign reading "营业中" glows above the doorway.`
- 指定字体、颜色、位置，加一句"清晰锐利、动态下可读"。

## 运镜写法（详见 运镜词典.md）

- `The camera pushes in with small amplitude at slow speed toward...`（类型+幅度+速度写成句内动作）
- 一镜一个运镜；只改变距离用运镜，不切镜。

## 负面项写法

官方没有独立负面提示词框。把"不要出现什么"写成时间线里一句正常句子：

```
Do not add hands, packaging, liquid, smoke, or extra props.
No subtitles, no on-screen text, no watermarks. Keep the logo unchanged.
```

## 长度参考

- 上限 7000 字符；官方可复现案例 300–700 英文词。
- 中位长度即可（中文约 130 字）——结构完整 > 字数堆砌。
- 每个字必须对应可见/可听的东西；"高级、电影感、炸裂"不产生任何镜头。

## 生成前自检清单

- [ ] 动作能在 12 秒内完成？太长先删情节，不要加切镜
- [ ] 第 1 镜无时间戳，第 2 镜起时间戳递增
- [ ] 每镜只有一个运镜
- [ ] 每个说话人有固定编号，`<d>` 内只有台词
- [ ] 声音三层都写了：对白/同步音在时间线，环境声在 soundscape，配乐在 non_diegetic_music
- [ ] 无配乐写了 N/A
- [ ] 图生视频：先写"保持图中 XX 不变"，再写会动什么；不要重新描述整张图
