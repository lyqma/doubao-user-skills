# 运镜词典

## 写法公式

完整运镜 = **运动类型 + 幅度（可选）+ 速度（可选）**

- 幅度：`with small amplitude`（小幅）/ `with large amplitude`（大幅）；中等幅度可省略
- 速度：`at slow speed`（慢）/ `at fast speed`（快）；正常速度可省略
- 运镜必须写成句子里的自然动作，不能堆在句尾当标签

正确示范：`The camera pushes in with small amplitude at slow speed toward the folded letter in her hands.`

## 社区进阶运镜（电影感利器）

| 术语 | 效果 | 适合场景 |
|---|---|---|
| Dolly zoom（希区柯克变焦） | 机身推近同时焦距拉远，透视扭曲 | 悬疑、惊悚、揭示 |
| Crane shot / Jib（升降臂） | 机位大幅升起或降下 | 开场、宏大揭示、收尾 |
| Steadicam / Gimbal（斯坦尼康） | 平滑漂浮跟随 | 边走边说、沉浸跟拍 |
| Whip pan（甩镜） | 镜头极快横甩带模糊 | 转场、能量、混乱 |
| Rack focus（焦点转移） | 前景→后景焦平切换 | 引导注意力、揭示 |
| Dutch angle（荷兰角） | 镜头沿轴倾斜 | 不安、紧张、失衡 |
| Handheld（手持） | 轻微晃动、有机感 | 纪录片感、紧迫、真实 |
| Locked-off（锁机位） | 完全静止 | 仪式感、紧张、精确 |
| SnorriCam（贴身机） | 机位绑演员身上，背景动 | 失重、角色聚焦 |
| Slow creep zoom（慢爬变焦） | 极慢极慢推近 | 累积恐惧、微妙强调 |

## 切镜规则

- 第 1 镜不写时间戳；第 2 镜起写 `[Shot 2] At 00:03.500, the camera cuts to...`
- 切镜动词：`the camera cuts to` / `the shot transitions to` / `the shot changes to` / `the shot switches to`
- 显式要求才用叠化/淡入淡出/划变：cross-dissolve / fade / wipe
- 切镜必须带来新信息；只有景别/角度微调时用运镜而不是切镜
- 时间戳严格递增、精确到毫秒、落在总时长之内

## 常见错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 一镜写多个运镜 | 互相抵消，画面乱 | 一镜只留一个，换机位就切镜 |
| "高级运镜""动感镜头" | 模型无从执行 | 写出具体类型+方向+幅度+速度 |
| 全程无运镜 | 幻灯片感 | 至少给每镜一个动作或机位变化 |
| 切镜太多太快 | 单镜不足1.5秒，动作完不成 | 按时长预算：4-6s用1-2镜，7-10s用2-3镜，11-15s用3-5镜 |
