# 灯光词典

灯光是电影感的第一来源。写清**光源位置、光质、方向**，比写"高级打光"有用一百倍。

## 常用灯光术语

| 术语 | 效果 | 适合场景 |
|---|---|---|
| Golden hour（黄金时刻） | 暖调、长影、柔和方向光 | 温情、浪漫、史诗 |
| Blue hour（蓝调时刻） | 冷紫蓝、暮色、神秘 | 城市夜景、悬疑、高级感 |
| Rembrandt lighting（伦勃朗光） | 脸颊一侧三角光斑 | 人物肖像、戏剧 |
| Butterfly lighting（蝴蝶光） | 鼻下蝶形阴影，柔美 | 美妆、时尚、肖像 |
| Split lighting（分割光） | 半脸亮半脸暗 | 戏剧、酷感、双面人格 |
| Rim light / Backlight（轮廓光） | 主体边缘勾光，与背景分离 | 突出主体、舞台感 |
| Chiaroscuro（明暗对照） | 强对比大块明暗，卡拉瓦乔式 | 古典、暗黑、悬疑 |
| Neon noir（霓虹 noir） | 彩色霓虹+雨+湿地面反光 | 赛博、犯罪、夜城 |
| Practical lights（可见光源） | 画面内可见的灯/屏幕/招牌 | 真实感、氛围 |
| Soft diffused（柔光） | 无硬影，柔光箱/阴天感 | 干净、商业、日常 |
| Hard sunlight（硬阳光） | 直射、锐利阴影、高对比 | 西部片、纪实、戏剧 |
| Motivated lighting（动机光） | 光来自画面内可见光源 | 真实可信 |
| Silhouette（剪影） | 主体暗、背景亮 | 悬念、宏大、简洁 |
| God rays（丁达尔光柱） | 光束穿过雾/尘/林 | 神圣、宏伟、氛围 |
| Lens flare（镜头光晕） | 光直射镜头产生光斑 | 能量、真实镜头感 |

## 写法要点

- 光写位置和方向，别只写"亮"：`A narrow warm light rakes across the surface from frame left.`
- 时间决定一切：先定时段（黄金/蓝调/正午/深夜），再定主光源。
- 用"光源在世界中的位置"保持跨镜头连续：换机位改变的是屏幕方向，不是灯的位置。
- 每镜给 1 个主光源 + 可选的 1 个轮廓光即可，不要堆 5 种灯。

## 氛围快选

| 想要的感觉 | 直接写 |
|---|---|
| 高级商业 | clean, premium, soft diffused key light, studio lighting |
| 悬疑惊悚 | low-key, chiaroscuro, single practical source, deep shadows |
| 赛博夜景 | neon noir, colored neon reflections on wet asphalt |
| 复古胶片 | warm tungsten, golden hour, practical lamps |
| 末日荒凉 | hard sunlight, blown-out sky, long harsh shadows |
| 梦幻柔美 | golden hour backlight, soft diffused, gentle haze |
