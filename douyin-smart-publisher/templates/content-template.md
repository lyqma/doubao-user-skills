# 抖音发布内容模板（短剧解说·商单投稿版）

## 标题模板（≤55字）
```
{悬念/痛点} + {剧名/关键词} + {行动指引} + emoji
```

**短剧解说示例（≤55字）：**
- 铡刀落下前，满朝无人敢救他！铁笔斩凶顽，点下方链接看全集 🔥
- 皇城脚下谁说了算？这道铡刀专斩权贵！看全集点视频下方链接 👀
- 包拯后人出手，满朝权贵慌了！免费看全集入口在下方链接 ⚡

## 正文模板（50-200字，三行）
```
第一行：核心钩子（最吸睛的剧情点/冲突）
第二行：补充说明/痛点共鸣（身份、悬念、反转）
第三行：行动指引/引导评论（点下方链接看全集、评论区聊聊）
#精准话题 #泛话题 #热度话题
```

**示例（铁笔斩凶顽）：**
```
第一行：公堂之上，铡刀已架好，满朝无人敢求情！
第二行：包拯后人铁面无私，这一次要斩的是当朝权贵。
第三行：后续剧情更狠，点我视频下方链接看全集！
#铁笔斩凶顽 #短剧推荐 #包拯 #古装短剧 #追剧
```

## 话题策略
- 1-2 个精准话题（剧名：铁笔斩凶顽、麦芽微剧）
- 1-2 个泛话题（短剧推荐、古装短剧、追剧）
- 1 个热度话题（包拯、悬疑短剧、抖音短剧）

## 封面规范
- 9:16 竖版 1080×1920
- 大字 + 高对比 + 关键帧（冲突最强烈的画面）
- 文字 ≤8 字，如"铡刀落下" "满朝无人敢救"

## 视频规范
- 15 秒 - 10 分钟（商单任务 60 秒-20 分钟）
- 1080×1920 竖版
- 前 3 秒强钩子（冲突/悬念画面）

## 发布时段
- 工作日 12-13 点、18-21 点；周末全天
- 商单任务在投稿截止前分时段多次投（不限次）
