# 抖音智能发布

- 来源：LobeHub aaaaqwq/agi-super-team（作者 Daniel Li）
- 适配环境：本机浏览器自动化（computer_use_tool plane="bu"）+ ffmpeg 工具链

## 排版规则

| 项 | 规则 |
|---|---|
| 标题 | ≤55 字，公式：悬念/痛点 + 关键词 + 行动指引 + emoji |
| 正文 | 0-500 字（视频描述），建议 50-200 字，前 3 行放核心 |
| 话题 | #话题名 3-5 个，精准话题在前 |
| 封面 | 9:16 竖版 (1080×1920)，大字 + 高对比 + 关键帧 |
| 视频 | 15 秒 - 10 分钟，最佳 1-3 分钟 |
| 最佳时间 | 工作日 12-13 点、18-21 点，周末全天 |

## 内容适配模板

将任意内容转化为抖音格式时：

1. **标题**：提炼核心卖点，套用公式 `悬念/痛点 + 关键词 + 行动指引 + emoji`
   - 例：`🔥打工人必看！5个效率工具让你准时下班`
   - 例：`👀不会还有人不知道这个神器吧？`

2. **正文排版**（视频描述）：
   ```
   第一行：核心钩子（最吸睛）
   第二行：补充说明/痛点共鸣
   第三行：行动指引/引导评论
   #话题1 #话题2 #话题3
   ```

3. **emoji 策略**：标题 2-3 个，正文每段 1 个

4. **话题策略**：1-2 个精准话题 + 1-2 个泛话题 + 1 个热度话题

## 发布流程（Browser 工具操作）

### Step 0: 确认发布内容类型
- 视频 → 走视频发布流程；图文 → 走图文发布流程

### 🎬 视频发布流程

**Step 1: 打开发布页面**
```
浏览器导航到 https://creator.douyin.com/creator-micro/content/upload
```
（短剧商单任务投稿：从任务详情页点"上传视频"，URL 带 order_id，任务组件自动挂载）

**Step 2: 等待页面加载**
- 等待创作者平台完全加载；检查是否已登录（未登录需扫码）

**Step 3: 上传视频文件**
- 点击上传按钮或使用 `input[type=file]` 上传视频
- 等待视频上传和转码完成（进度条）
- 本环境：`bu.upload_file('input[type=file]', 本地mp4路径)`

**Step 4: 填写标题**
- 定位标题输入框：查找 placeholder 含"标题"的输入框
- 用 JS 精确填充：
```javascript
const titleInput = document.querySelector('input[placeholder*="标题"], textarea[placeholder*="标题"]');
if(titleInput) { titleInput.value = '视频标题（≤55字）'; titleInput.dispatchEvent(new Event('input', {bubbles: true})); }
```
- 本环境：`bu.fill_input('input[placeholder*="标题"]', title)`

**Step 5: 填写正文（视频描述）**
- 点击描述输入框获取焦点，用 Clipboard API 粘贴正文（富文本编辑器问题通用解法）：
```javascript
const descInput = document.querySelector('.ql-editor, textarea, [contenteditable="true"]');
if(descInput) {
  descInput.click();
  await new Promise(r => setTimeout(r, 300));
  const text = '要粘贴的正文内容';
  const dt = new DataTransfer();
  dt.setData('text/plain', text);
  descInput.dispatchEvent(new ClipboardEvent('paste', {clipboardData: dt, bubbles: true}));
}
```

**Step 6: 添加话题标签**
- 在正文中添加 #话题名，或找到标签输入框添加

**Step 7: 设置封面（可选）**
- 选择视频关键帧作为封面，或上传自定义封面图（9:16, 1080×1920）

**Step 8: 截图预览（关键）**
- 截图当前填写内容的页面，发给用户确认，汇报进度

**Step 9: 等待确认后发布**
- 用户确认后点击「发布」按钮，或点击「保存到草稿箱」

### 📷 图文发布流程
同视频流程，Step 2 选"图文"模式，Step 3 上传 1-20 张图片（9:16 最佳），其余相同。

## 自动化脚本用法

```
python scripts/douyin_publish.py \
  --title "标题文字" \
  --content "正文内容" \
  --tags "话题1,话题2,话题3" \
  --video "/path/to/video.mp4" \
  --mode draft \      # draft=存草稿（默认），publish=直接发布
  --auto-login        # 自动连接浏览器获取登录态
```

参数说明：
- `--auto-login`：自动复用本机浏览器登录态
- `--mode draft`：保存到草稿箱（默认）
- `--mode publish`：直接发布

## 浏览器自动化注意事项

### 已登录态获取
使用浏览器自动化（本环境 bu）复用创作者中心登录态；若登录失效，提示用户扫码。

### 二次创作去重规则（防同质化/搬运判定，强制）

**原则：只拼接原片 = 搬运，必被限流。每条必须带二创层。**

1. **重排倒叙开场**：不要按原剧顺序剪。第一段取本集最高能段（惊险/反杀/大喊/冲镜头），让前3秒直接落在冲突上。
2. **解说配音/文案层**：画面必须叠加自己的表达——
   - 片尾引流配音（必做，低沉男声："想看后续剧情？点击左下角链接，看全集！"）
   - 段间解说字幕（原创文案，白色/黄色小字 36-40px，放屏幕上1/4处，**绝不压原剧底部字幕**）：
     * 开场0-3s钩子字幕（如"被人推下水那晚，她默默抄起了眼镜蛇——"）
     * 每次转场前1-2s一句解说（讲剧情/情绪/感受，用大白话，不照搬原台词）
3. **变速卡点**：关键情绪处放慢（0.9-1.0x），转折处加速（1.1-1.2x），音视频同步变速（ffmpeg atempo）。
4. **基础差异**：放大102-105%（scale>原尺寸再crop）+饱和度/对比±5%，**禁镜像翻转**。
5. **蒙版遮原字幕（可选）**：原剧字幕被复用率高时，用矩形模糊/drawbox遮挡底部字幕区。
6. **去重检查清单**：拼接≥3段不同时间点高光段、段间硬切跳接、有解说字幕、有引流配音、变速≥1处、画面微放大裁边。

## 常见问题与解决方案

| 问题 | 根因 | 解决方案 |
|---|---|---|
| 正文框写不进去 | 抖音用富文本编辑器 | Clipboard API 模拟粘贴（见 Step 5） |
| 视频上传失败 | 格式/大小/网络 | 压缩为 MP4（推荐≤4GB、1080×1920），重试 |
| 登录过期 | Cookie 失效 | 提示用户重新扫码登录 |
| 滑块验证 | 风控 | 暂停等待手动完成，不设无头模式 |
| 标题超长 | 超 55 字 | 自动截断到 55 字并警告 |
| 网络超时 | 网络波动 | 重试 3 次，指数退避 (5s/15s/45s) |
| 发布频率限制 | 频率过高 | 等待 60 秒后重试 |

## 差异化去重剪辑法（强制规则，防"同类视频重复"限流）

平台对同一部短剧的推广视频查重极严：整段搬运一集（尤其只截一集的后半截）会被判"与同类账号作品高度重复"，出现"流量减少/限制传播"。**必须做多段拼接二创**，禁止整段截取。

- **单集多段拼接**：在一集素材里挑 3-4 个高光段（不同时间点），跳切拼接成一条，段间硬切（或白闪/黑闪 1-2 帧转场），打乱原始时间轴顺序（高光可前置）。
- **多集混剪**：需要更长成片时，跨集挑高光段拼接（注意任务"可剪辑集数上限"，超上限会处罚）。
- **全局微调去重**：轻微放大裁边（如 scale=1072 后 crop 回 1080，约裁 1% 边）、饱和度/对比度微调（±5%）、必要时轻微音调/音量 normalize；**禁止镜像翻转**（会把字幕镜像成反字，暴露搬运）。
- **结构不变**：0-3s 最高能开场 → 多段冲突密集推进 → 结尾卡付费悬念节点（情绪顶点/身份爆点/威胁质问）→ 片尾定格压暗 + 配音引流 + 上部小字引流字幕（不压底部原剧字幕）。
- **时长规则**：拼接总长必须 > 任务要求（如 60 秒），上限参考任务规定。

## 高光时刻剪法（短剧推广核心方法）

### 什么是高光时刻
视频中最能引爆观众情绪、最抓眼球、最有传播价值的片段。短剧推广 = 把高光时刻前置（开头3秒定生死），中间连续爆点，结尾卡付费节点。

### 高光时刻的 10 种类型（识别标准）
1. **冲突爆发**：争吵、对峙、打斗（大喊大叫）
2. **极限情境**：惊险、濒死、危险动作
3. **强反转**：真相揭露、身份曝光、骗局揭穿
4. **高燃名场面**：逆袭、装逼打脸、霸气宣言
5. **情绪顶点**：大哭、崩溃、虐心泪点
6. **视觉冲击**：冲入镜头、大场面、爆炸、撞车
7. **悬念缺口**：抛出关键问题不解答
8. **金句台词**：一句话定全局
9. **关系爆点**：表白、决裂、离婚、背叛
10. **音效冲击**：爆点音效、音乐骤停、静默

### 爆款结构（配合任务规则 60 秒+）
- **0-3 秒**：最高能片段直接开场，不铺垫
- **3 秒 - 尾段**：5-10 秒一个爆点，快节奏串联，删掉拖沓
- **结尾**：卡在付费悬念节点（最心痒处）
- **配音策略**：开头不配解说——让剧情原音自己播（30 秒/55 秒或合适位置），**最后一句**才加引流语："想看后续，点击下方链接/下集"
- 全程带剧名字幕、短剧画面占比 100%、挂付费组件

## 发布成功后素材清理（强制规则）

**规则：只要视频发布成功（抖音侧显示"已发布"或"审核通过"），必须立即删除本地原素材，不得留存。**

### 删除范围

1. 任务方提供的原素材（百度网盘等下载的剧集片段、素材包、参考图）
2. 剪辑中间产物（剪辑工程、分段片段、临时渲染文件）
3. 成片 MP4（投稿完成后不再保留）

### 执行方式

- Windows：`Remove-Item -Path <文件路径> -Force`
- 删除前先记录文件清单（路径 + 大小），便于核对
- 删除后确认文件已不存在，再向用户汇报"素材已清理"

### 目的

- 版权合规：商单素材仅授权用于该任务投稿，禁止留存、二次使用或转售
- 账号安全：防止误用未授权素材发布其他内容导致限流/封号

### 例外

- 仅当用户**明确主动要求**保留素材时，才不删除。
