# doubao-skills

豆包（Doubao）智能体用户自建技能集。由用户在工作区中创建/安装，涵盖视频创作、ComfyUI、CAD/3D 打印、战略方法论、新媒体写作、图像生成等多个领域。

> 说明：本仓库仅包含用户自建技能，不含豆包内置预置技能。

## 安装方式

将需要的技能文件夹复制到豆包工作区的技能根目录（如 .user_skills）即可。
