# 星图短剧商单自动化

把抖音短剧商单投稿变成一条无人值守的赚钱流水线。核心节奏（用户强制要求）：**下一个 → 剪一个 → 发一个 → 删一个**，绝不同时批量下载、批量剪辑，防止电脑崩盘；发布成功立即删本地全部素材（源片、中间产物、成片），一个不留。

## 总目标

- 账号收益 = 付费分佣（如 70%）+ 广告分成（如 70%），按任务"考核指标"（付费金额、广告消耗）混合分成结算。
- 一条任务可发多条，收益叠加；任务有截止日期和可剪辑集数上限，过期/超集数会处罚。

## 一、完整流水线（从0到1）

### 第1步：找任务（变现广场）
1. 浏览器打开 `https://creator.douyin.com/creator-micro/revenue/center`（收入变现 → 现金广场/变现广场）。
2. 筛选**短剧/漫剧商单**：优先看
   - **付费分佣比例 + 广告分成比例**（70%+70% 为佳，50%+50% 次之）
   - **投稿截止时间**（距今越近越优先，别接已截止的）
   - **可剪辑集数上限**（决定能发几条）
   - **付费内容组件已挂载**（有短剧ID）
3. 题材按用户要求挑（如"重生"相关、CG真人、古言女频），用户否决的任务立即换，不自作主张。
4. 记录：任务详情页 URL、任务ID、付费组件短剧ID、素材网盘链接、话题格式（如 `#抓包夜重生，我带女儿斩情仇@慕凡女频短剧`）、分佣比例、截止时间、可剪集数。

### 第2步：接收任务
- 详情页点 **"我要投稿"** → 弹出"任务内容授权确认函"（是否确定参与投稿并授权客户投放广告）→ 点 **"确定"**。
- 接收成功后详情页出现"投稿/取消任务"，任务状态变为"未开始"。

### 第3步：取素材（一次只取1-2集）
- 素材在百度网盘分享链接，**必须用桌面版网盘客户端下载**（网页端下载按钮一律弹"使用客户端下载"，预览流 API 拿不到，勿再试）。
- 用户给出素材目录（如 `D:\BaiduNetdiskDownload\电影\` 下的 `1-15.mp4`，单集约 96-140 秒，1080×1920 竖版 25fps）。
- **只下载接下来要做的 1-2 集**，禁止全选批量下载（会占满磁盘/CPU 导致系统卡死，见第四节SOP）。
- 下载中/已完成状态：文件名带 `downloading` 后缀=未完成，不要用。

### 第4步：看素材挑高光（核心判断）
1. `ffprobe -v error -show_entries format=duration` 拿时长。
2. 抽帧网格看内容：`ffmpeg -ss 0 -i 素材.mp4 -vf "fps=1/6,scale=240:-1,tile=5x3" -frames:v 1 网格.jpg`（中段/尾段用 `-ss 60`、`-ss 100` 再抽，3 张网格覆盖全集）。
3. 读帧图识别**高光时刻**（10类见第五节）和剧情转折，挑出本集 3-4 个高能段（起止时间）。
4. 高光识别范例：《抓包夜重生》13集 = 影院撞破偷情（"你就是这样见客户的/她是谁啊"）→ 江瀚倒打一耙（"实际越轨就是你被别的男人"）→ 挽月爆发（"你还能再无耻一点吗"）→ 被诬陷辩解（"昨晚我出去喝酒/你原谅我这一次"）。

### 第5步：二创剪辑（防搬运/同质化，强制）
用 ffmpeg 按「差异化去重剪辑法」（第六节）处理：**倒叙重排 + 3-4段跳切 + 放大裁边 + 饱和微调 + 段间解说字幕 + 片尾定格压暗 + 片尾引流配音 + 剧名字幕**。全程保留剧情原音，配音只加在片尾引流句。

### 第6步：校验成片（发布前必查）
- `ffprobe` 时长 **必须 > 60 秒**（任务硬性要求）。
- 抽片头帧（解说字幕正常）、片尾帧（引流语+剧名在屏幕上部、**不压原剧底部字幕**）。
- 画面占比 100%（全屏短剧画面，无其他平台水印）。

### 第7步：投稿发布
1. 任务详情页点 **"上传视频"**（进入 `content/upload?order_id=…`）。
2. `bu.upload_file('input[type=file]', 成片mp4)` 上传；等跳转 `content/post/video?order_id=…&enter_from=publish_page`。
3. 填标题：**≤30字**（发布页实测30字，非55字），公式=悬念+爆点+结果，如"影院撞破老公偷情！他还反咬一口：是你越轨！"。
4. 填正文：钩子+剧情+引导（"点击左下角链接，看全集"）+ **任务话题**（`#剧名@出品方`，如 `#抓包夜重生，我带女儿斩情仇@慕凡女频短剧`）。
5. 等页面出现"重新上传"=上传完成；滚到底点 **"发布"**。
6. 跳转 `content/manage?enter_from=publish`，查页面尾部"发布成功"才算真成功。

### 第8步：发布成功后立即删素材（强制）
- 删除范围：**源片**（如 `电影\13.mp4`）+ **工作目录**（分段/帧图/成片，一个不留）。
- 先记录清单再删，删除后核对文件不存在，再向用户汇报"素材已清理"。
- 唯一例外：用户明确要求保留。

### 第9步：循环下一条
- 回到第3步，只下下一集；第4-8步串行执行，**不做并行**。
- 用户说"继续/下一集"=直接进入下一条；用户说"换剧情/换电影"=回到第1步换任务。

## 二、卡死/下载占满恢复SOP（用户点名必读）

### 症状
- `Bash` 连 `echo` 都 timeout；`computer_use_tool`（bu/cu）全部 timeout，连续 1 小时以上不恢复。

### 根因（最可能）
- **百度网盘桌面客户端全速下载**，写盘+CPU 占满导致整个系统（含 agent 工具通道）无响应。
- 次要：磁盘空间耗尽、杀毒扫描、系统休眠。

### 处理步骤（按顺序）
1. **立即请用户暂停或退出百度网盘客户端**（下载进度自动保存，下次打开可续传）。这是唯一有效解法，不要反复重试工具。
2. 用户暂停后，等 30-60 秒，先跑最小命令（`echo ALIVE`）确认工具通道恢复。
3. **恢复后先核验、不重做**：检查上次发出但未确认的动作是否真的完成了——
   - 发布：去 `content/manage` 查该条是否已"发布成功"（已成功就不要再发一遍）。
   - 删除：查源片/工作目录是否已不存在（已删就不要再删）。
   - 只补做未完成的那一步，不重复已完成的步骤。
4. 向用户汇报：卡死原因、恢复动作、当前流水线位置（第几条/哪一步）。

### 预防（写入习惯）
- 一次只下 1-2 集，下完即用、用毕即删，磁盘常保余量。
- 发布成功后第一时间删素材，不留大文件堆积。
- 大文件操作（下载/转码）期间不并行跑其他重操作。

## 三、任务发布硬性规则（按任务要求逐条核对）

- 视频时长 **> 60 秒**（任务非硬性要求里写死）。
- 短剧画面占比 **100%**。
- 内容与小程序主题相关，**杜绝生硬植入**；积极向上，禁止恶俗、违背公序良俗或品牌负面内容。
- 挂载**付费内容组件**（投稿入口进入自动挂载，勿用普通发布入口）。
- 话题按任务指定格式写（如 `#抓包夜重生，我带女儿斩情仇@慕凡女频短剧`）。
- 遵守"可剪辑集数上限"（如发布当天~第2天14集），超上限的集数（如15集）不可用。
- 不支持图集投稿（视频任务必须传视频）。
- 标题 ≤30 字；正文 ≤1000 字。

## 四、高光时刻剪法（短剧推广核心）

### 高光时刻定义
视频中最引爆情绪、最抓眼球、最有传播价值的瞬间。短剧推广 = **高光前置**（前3秒定生死）→ 中间连爆点 → 结尾卡付费悬念节点。

### 10种高光类型（识别标准）
1. **冲突爆发**：争吵、对峙、打斗、大喊大叫
2. **极限情境**：惊险、濒死、危险动作
3. **强反转**：真相揭露、身份曝光、骗局揭穿
4. **高燃名场面**：逆袭、打脸、霸气宣言
5. **情绪顶点**：大哭、崩溃、虐心泪点
6. **视觉冲击**：冲入镜头、大场面、爆炸、撞车
7. **悬念缺口**：抛关键问题不解答
8. **金句台词**：一句话定全局
9. **关系爆点**：表白、决裂、离婚、背叛
10. **音效冲击**：爆点音效、音乐骤停、静默

### 爆款结构（配合 >60秒 任务规则）
- **0-3秒**：最高能片段直接开场，不铺垫。
- **中段**：5-10秒一个爆点，快节奏串联，删拖沓。
- **结尾**：卡付费悬念节点（最心痒处）。
- **配音策略（用户强调）**：开头**不配解说**——剧情原音自己播；到 30 秒/55 秒或合适位置之后，**最后一句**才加引流语："想看后续剧情？点击左下角链接，看全集！"（text_to_audio_plus 生成，低沉男声 5-6 秒存 yindao.wav）。
- 全程带剧名字幕。

## 五、差异化去重剪辑法（防"同类视频重复"限流，强制）

**只拼接原片 = 搬运，必被限流**（已验证：整段截取一集被判"与其他账号作品高度重复/流量减少"）。每条必须带二创层：

1. **重排倒叙开场**：第一段取本集最高能段，前3秒直接落在冲突上，不打乱后原剧顺序。
2. **多段跳切**：在一集里挑 3-4 个不同时间点的高光段拼接，段间硬切（可白闪/黑闪1-2帧转场）；需要长片可跨集混剪但**不超可剪集数上限**。
3. **解说字幕层（原创）**：开场0-3s钩子字幕 + 每次转场前1-2s一句大白话解说（讲剧情/情绪，不照搬原台词）。36-40px，白色/黄色，放屏幕**上部1/4处**（y≈430），**绝不压原剧底部字幕**。
4. **变速卡点**：关键情绪放慢（0.9-1.0x），转折加速（1.1-1.2x），音视频同步（ffmpeg `setpts=PTS/1.15` + `atempo=1.15`）。
5. **基础差异**：`scale=1100:1956,eq=saturation=1.06:contrast=1.04,crop=1080:1920,setsar=1`（放大裁边去重）；**禁止镜像翻转**（会把字幕反成反字）。
6. **片尾定格压暗**：尾帧 `eq=brightness=-0.22` + 引流配音 + 双字幕（引流语 y≈480 白色40px、剧名 y≈590 黄色36px），enable 时间 = 主片结束点之后（如主片88s → `between(t,88.2,93.3)`）。
7. **去重检查清单**：拼接≥3段、段间硬切、有解说字幕、有引流配音、变速≥1处、画面微放大裁边。

## 六、ffmpeg 要点速查

- 抽帧网格：`ffmpeg -y -v error -ss 0 -i in.mp4 -vf "fps=1/6,scale=240:-1,tile=5x3" -frames:v 1 grid.jpg`
- 分段提取：`ffmpeg -y -v error -ss 60 -t 20 -i in.mp4 -vf "scale=1100:1956,eq=saturation=1.06:contrast=1.04,crop=1080:1920,setsar=1" -c:v libx264 -crf 22 -preset medium -c:a aac -b:a 192k seg_a.mp4`
- concat 列表文件：`file '路径\seg_a.mp4'` 每行一个，**ASCII 无 BOM**；`ffmpeg -f concat -safe 0 -i list.txt -c copy main.mp4`
- 合成成片：主片 + `-loop 1 -t 5.5` 定格帧 + yindao.wav，filter_complex 里 concat 音视频 + drawtext 字幕（见第五节）。
- 常用路径（旧Windows环境）：工作目录 `C:\Users\Administrator\Doubao\chats\<日期>\new-chat-N\duanju\<剧名缩写>\`；中文字体 `simhei.ttf` 放该目录，drawtext 用 `fontfile='C\:/.../simhei.ttf'`（冒号转义）。

## 九、常见问题

| 问题 | 处理 |
|---|---|
| 发布页标题限制 | 以发布页实测为准（≤30字），超长截断 |
| 正文写不进去 | 富文本编辑器：snapshot 找 `[edit]` ref → click → type 全文 |
| 上传后无反应 | 等"重新上传"出现再操作；没出现前不要点发布 |
| 找不到"上传视频"按钮 | 详情页先点"我要投稿"→弹窗"确定"接收任务，接收后才有上传入口 |
| 视频被限流/重复判定 | 回查二创层（拼接段数/解说字幕/变速/裁边），重剪再发，勿原片重发 |
| 网盘网页端下不动 | 必须桌面版客户端；网页端/预览流是死路，勿重试 |
| 系统卡死 | 见第二节SOP：暂停网盘 → 恢复 → 核验不重做 → 汇报 |

## 十、与既有技能的关系

- `douyin-smart-publisher`：通用抖音发布排版（标题公式/正文/话题/封面）——本技能在商单场景下以任务规则为准（标题30字、话题任务指定）。
- `auto-douyin`：通用自动上传发布——商单投稿必须走任务详情页入口（组件自动挂载），勿用普通发布入口。
- 本技能是**商单投稿的完整主流程**，两者是其子集参考；执行以本技能为准。
