# 场景一致性 v4.0

## 这个技能干啥

以用户上传的**一张场景母版图**为基准，**只移动相机**，产出同一场景的新视角。三种执行模式：

- **模式 A · 静态多视角图**：输出不同机位的静态图片。
- **模式 B · Prompt 驱动镜头转移视频**：用文字描述轨迹，`image_to_video` 生成相机运动视频。
- **模式 C · 首尾帧精确转移视频**：先 `image_edit` 出目标机位尾帧静态图，再用首帧（母版）+尾帧两张图生成中间转移视频，终点 100% 可控。

核心硬约束：**只动相机，场景空间结构、物品位置、材质、光源方向、色调、风格全部与母版一致，不新增、不删除、不移动任何场景物体。**

## 触发词

- "场景一致性"、"根据这张图换个角度"、"多机位分镜场景别变"
- "镜头转移"、"镜头移动"、"机位转移"、"空间位置转换"
- "推近/拉远/环绕/摇过去/升起来/横移"
- "dolly in/out"、"orbit"、"pan/tilt"、"zoom"、"fly through"
- "从这张转到那张"、"首尾帧"、"精确终点"

## 第一步：判模式

| 用户表达 | 模式 |
|---|---|
| "出几个角度"、"换几张静态图" | A |
| "出一段视频，镜头推近/环绕"、大概方向就行 | B |
| "终点要精确停在XX视角"、"从A图转到B图"、"不要不知道最后停哪" | C |
| 没明说但要动态过程 | B |

判断不清用 `interaction.ask`。

## 第二步：读母版定基准清单

1. 空间布局：主体位置、朝向、数量、间距、对称关系。
2. 关键物体：形态、材质、颜色、尺寸。
3. 光源：主光方向、色温、灯位、倒影。
4. 色调风格：冷暖、饱和度、质感。
5. 文字招牌：位置、内容、字体颜色。
6. 相机三维参数（新增）：当前 azimuth 方位角、elevation 仰角、distance 距离，作为轨迹起点。

## 模式 A · 静态多视角图

1. 机位清单：用户指定按用户的；默认一套——正面平视、左45°、右45°、低机位仰拍、顶部俯视、背面反打。
2. 逐机位 `image_edit`，传母版图 URL。Prompt：保留全部物体与空间结构，只改机位/角度，材质光线色调风格一致，透视符合真实物理，不扭曲穿模。
3. 每张立即单独 `present_files` 交付。
4. 对照基准清单自检，配镜头说明。

## 模式 B · Prompt 驱动镜头转移视频

### 工具参数

- 工具：`image_to_video`，母版图作首帧。
- 模型：默认 `seedance_2.0_fast`（5–15秒）；长镜头用 `seedance_2.5`（5–30秒）。
- 时长：短运动 5 秒；大环绕/横穿 8–10 秒。
- 比例：严格继承母版。

### 相机轨迹类型表

| 类别 | 轨迹 | 英文 | 动作 |
|---|---|---|---|
| 直线 | 推近 | dolly in / zoom in | 向前，主体变大 |
| | 拉远 | dolly out / pull back | 后退，环境展开 |
| | 前进穿越 | move forward / fly through | 向前穿过门洞/街道 |
| | 后退揭示 | move backward / reveal | 后退带出环境 |
| 横移 | 左移/右移 | truck left/right | 横向平移 |
| 升降 | 升起/降下 | crane up/down | 垂直升降 |
| 摇摄 | 上摇/下摇 | tilt up/down | 原地垂直转 |
| | 左摇/右摇 | pan left/right | 原地水平转 |
| 环绕 | 半圈/整圈 | orbit 180°/360° | 绕主体水平旋转 |
| | ∞形 | lemniscate | 走8字形 |
| | 螺旋 | spiral | 边升边绕 |
| 特殊 | 希区柯克变焦 | dolly zoom | 推轨+反向变焦 |
| | 倾斜滚动 | roll | 荷兰角 |
| | 斜向转移 | diagonal dolly | 斜移到侧前方 |

### 相机三维参数（MiniMax H3 精确控制用）

复杂运动时除轨迹类型外，记录三个参数：
- **azimuth 方位角**：绕主体水平旋转角度（0=正面，90=侧面，180=背面）
- **elevation 仰角**：俯仰角度（0=平视，45=斜俯，90=正俯视）
- **distance 距离**：相机到主体距离

### 锁定模式

- **Frame Lock**：构图基本不变，只加景深微动。
- **Free Motion**：相机自由运动。
- **Subject Track**：运动中主体始终居中。

### Prompt 写作七原则

1. 前置运动动词（"相机缓慢推近..."）
2. 不复述图片内容（模型已看到）
3. 明确保留约束（"background geometry stable"）
4. 写速度节奏（slowly/匀速/5秒完成）
5. 写轨迹终点（"最终停在牌楼正前方人视高度"）
6. 写灯光保持（光源方向、色温、倒影不变）
7. 负面约束（不漂移、不新增、不变形）

### Prompt 模板

```
[运动动词]，相机从母版视角（[起点]）沿[轨迹]平滑运动到[终点]，全程[速度]、稳定无抖动，[锁定模式]。场景中所有建筑、街道、车辆、人物、招牌、灯笼、灯光、材质、色调、光源方向完全保持不变，背景几何稳定，不新增不删除不移动任何物体；透视符合真实物理，无扭曲穿模。画面保持母版[质感]。
```

### 长距离分段

- 短距离（推拉几米、摇<30°、半圈）：一段生成。
- 长距离（整圈、横穿大街、地面升高空）：分段，用上一段末帧作下一段首帧参考。

## 模式 C · 首尾帧精确转移视频（新增）

**适用**：用户要终点精确、防漂移、两个已知机位之间转移。

### 流程

1. **出尾帧静态图**：用 `image_edit` 基于母版图生成目标机位的静态图（即模式 A 的一张），确认尾帧构图满意。
2. **双图输入**：调用 `image_to_video`，`image_reference_url_list` 传 `[母版图URL, 尾帧URL]`。
3. **Prompt 明确双帧职责**：
   ```
   第一帧 [img0] 是起点机位，第二帧 [img1] 是终点机位。相机从 [img0] 的视角平滑、匀速运动到 [img1] 的视角，自然补全中间过程。全程场景建筑、物体、材质、灯光、色调与两帧完全一致，只移动相机，不新增不删除任何物体。运动轨迹为直线/平滑弧线，稳定无抖动。
   ```
4. 比例继承母版，时长 5–10 秒。
5. 生成后立即 `present_files` 交付。

### 首尾帧优势

- 终点构图 100% 锁定，不会"不知道最后停哪"
- 防物体漂移（两帧都锚定了场景布局）
- 适合：从航拍精确降到人视、从正面精确转到侧45°、两个已确认视角之间平滑过渡

## 本地 ComfyUI 相机控制（RTX 5080 本地模型对接）

用户本地有 ComfyUI + Wan2.2 / MiniMax H3 时，优先用本地模型出更高质量镜头运动：

### Wan2.2 Fun Camera（WanCameraEmbedding 节点）

| 参数 | 说明 |
|---|---|
| Camera Motion | Zoom In / Zoom Out / Pan Up / Pan Down / Pan Left / Pan Right / Static |
| Width/Height | 分辨率（16:9 用 1280×720 或更高） |
| Length | 帧数，默认 81 帧（约5秒@16fps） |
| Speed | 运动速度，默认 1.0 |

**Motion Bucket 参考值**（控制运动强度，需配合 prompt）：
- 缓慢推近：35–45
- 右摇揭示：40–55
- 戏剧推近特写：60–75
- 平滑环绕：45–60

Prompt 配合："camera slowly zooms in" / "camera pans right to reveal scene" / "dramatic push-in" / "smooth orbit around subject"。

### MiniMax H3 Camera Control

| 参数 | 说明 |
|---|---|
| azimuth 方位角 | 绕主体水平角度，如 0→45 表示从正面转到侧45° |
| elevation 仰角 | 俯仰角度，如 60→20 表示从高空俯拍降到斜俯 |
| distance 距离 | 相机到主体距离，如 20m→8m 表示推近 |
| timing | 运动时长/节奏 |

支持 orbit（环绕）、dolly（推拉）、elevation（升降），保持主体和场景一致。

### LTX-2 Camera Control LoRA

- `ltx-2-19b-lora-camera-control-dolly-right.safetensors`：横移右
- 对应 dolly left / jib up / jib down / static 等同系列 LoRA
- 需要精确横移/升降时加载对应 LoRA。

## 执行流程总览

1. 收母版图，上传拿 URL。
2. 判模式（A/B/C）。
3. 解析轨迹、起点终点、锁定模式、时长；信息不够问。
4. 模式 C：先 `image_edit` 出尾帧静态图并交付确认。
5. 走 `doubao-creative-video` 澄清与最终确认：展示完整参数，用户确认后才调视频工具。
6. 调用工具（`image_edit` 或 `image_to_video`）。
7. 成功后立即单独 `present_files` 交付。
8. 失败模式自检（见下），跑偏重生成。

## 失败模式自检清单

- [ ] 风格漂移：色调质感和母版不一致
- [ ] 结构扭曲：建筑变形、飞檐崩坏、穿模
- [ ] 物体漂移：固定物体位置移动或消失
- [ ] 新增物体：冒出母版没有的东西
- [ ] 灯光漂移：光源方向/色温/倒影改变
- [ ] 透视错误：近大远小关系不对
- [ ] 主体丢失：Free Motion 下主体跑出画面（改 Subject Track）
- [ ] 抖动卡顿：运动不平滑
- [ ] 终点跑偏（模式B）：建议改模式 C 首尾帧精确控制

## 硬规矩

- 只动相机，场景不动。
- 保留空间布局、物品位置、材质、光源、色调、风格。
- 透视符合真实物理，禁止扭曲穿模。
- 视频模式：建筑/招牌/固定道具全程锁定；人物/车流/灯火允许自然微动。
- 禁止重新设计场景、新增删除物体、改变光源方向。
- 没给机位/轨迹时：静态按默认清单；视频必须问清轨迹和终点。
