# 银丝古建对称群像

## 这个技能干啥
在门楼/牌坊/凯旋门这类中轴对称建筑的两侧绿化带，生成**左右严格镜像的人物雕塑群像 + 旗帜阵列 + 绿化带装饰**。核心价值是把"左右对称、人物数量准确、不被遮挡、间距相等"做成硬约束，避免AI把人物画乱、画少、画偏。

## 什么时候触发
用户说这些，就按本技能走：
- "左右两边都要有雕塑，要对称"
- "左边5个右边5个，你数数够不够"
- "人物还是少，左边4个右边3个，不对"
- "加旗帜，加雅典娜旗帜/罗马旗帜"
- "雕塑旁边再补点绿化带装饰"
- 任何"中轴对称场景 + 两侧多数量同构元素"的要求

## 执行步骤（分步走，一次只锁一件事，严禁一口气全塞）

### 第1步：锁定人物数量与对称锚点（最关键，先做这个）
1. 以**道路/建筑中轴线为唯一对称轴**，禁止"左边先摆、右边再补"。
2. 确定单侧数量 N，总数为 2N（例：左5右5=10尊）。**数量必须先和用户确认，不许自己拍板后又变。**
3. 明确人物清单，左右完全一致。门楼众神场景参考清单：
   - 雅典娜（主像，手持橄榄枝/盾牌）
   - 胜利女神尼刻（带羽翼，捧月桂花环）
   - 赫尔墨斯（信使，持双蛇杖）
   - 阿波罗（持里拉琴）
   - 古希腊/古罗马女祭司（持橄榄枝）
   > 罗马主题可替换：罗马统帅、角斗士、胜利女神、罗马使者、女祭司。清单变必改，左右同步。
4. 硬性约束写进提示词：**左侧N尊完整青铜群像，右侧N尊完整青铜群像，合计2N尊；以中轴线逐尊镜像，左1=右1、左2=右2…；所有雕像全身完整展示，无任何遮挡，可清晰逐个清点。**
5. 这一步只出人物轮廓、站位、间距和左右镜像，**暂不加旗帜、不加绿化带**，避免信息混杂又把人物吃掉。

### 第2步：检查并移除遮挡（人物计数被吃掉的头号原因）
AI生成人物群像时，旗阵、路灯、行道树、绿化带会自动压住雕塑，**一尊被挡一半，肉眼就数成少一尊**。所以：
1. 先找出人物展示带里的干扰物（旗杆、灯杆、树冠、灌木）。
2. **哪个干扰移除哪个，以雕像为主。** 把干扰物移到人物外侧，保证每尊全身可见。
3. 人物之间保持**等间距**，不重叠、不拥挤、不近远不一。
4. 需要计数更稳时，可临时给每尊加浅色轮廓+编号，交付后再去掉。

### 第3步：加旗帜（人物锁死后，旗帜只是氛围层）
1. 旗帜主题由用户指定（如希腊雅典娜、罗马鹰徽SPQR、蓝白旗阵）。
2. 旗帜**放大到有仪式感**，但只放人物外侧与背景空隙，**绝不进入人物轮廓区**（头、手臂、道具、躯干、脚都不能压）。
3. 旗帜也按中轴线左右镜像，数量一致。
4. 视觉层级固定：前景=人物，中景=旗帜，背景=门楼/路灯/树木/商铺。

### 第4步：补绿化带细节（最后一步，只填空隙）
1. 在人物之间的空隙加小比例元素：石柱、月桂树/橄榄枝、青铜花环、石质铭牌、小型奖杯、灯阵。
2. 只填充空隙，不占用人物主轮廓区，不改变人物数量。

## 硬规矩（必须/禁止）

### 必须做
- 每次都以"中轴线逐尊镜像 + 等间距 + 全身无遮挡"三件套为准。
- 分步执行：先人物、再旗帜、再细节；每步交付后等用户确认再进下一步。
- 数量变更必须左右同步（左5→右5，左4→右4），绝不出现左4右3。
- 旗帜放大、人物不动、外侧避让、镜像排布、层级分离。

### 禁止做
- 禁止"左边先摆右边再补"，一定会歪。
- 禁止一次性把人物+旗帜+装饰全塞进一个提示词。
- 禁止让人物被旗帜/路灯/树遮挡后还宣称"数量正确"。
- 禁止用户说"不对、还是少"时只改描述不改构图根因。
- 禁止擅自改变单侧数量；数量以用户最终确认为准。

## 输出格式
交付时给用户一张图，并在文字里明确报告：
- 单侧数量：左N + 右N = 共2N尊
- 对称方式：中轴线逐尊镜像
- 遮挡处理：移除了哪些干扰物
- 旗帜主题与层级
- 保留的原有元素（门楼、牌匾、浮雕、道路、车辆）

示例交付语：
> 已完成：左侧5尊、右侧5尊，共10尊，以中轴线逐尊镜像、等距、全身无遮挡；旗帜放大后放在人物外侧；绿化带补了石柱和花环。原有门楼、牌匾、浮雕不变。

## 根因排错（用户说"还是不对/还是少"时先自查这个）
| 现象 | 根因 | 处理 |
|---|---|---|
| 左4右3，怎么调都不对 | 人物被旗阵/路灯/树遮挡 | 先移除人物展示带干扰物 |
| 左边近右边远、间距不齐 | 不是全局镜像，是补位式摆放 | 以中轴线重排，等间距 |
| 单侧5尊挤成一团像1尊 | 绿化带太窄，人物重叠 | 扩大人物带/外移/适当放大 |
| 放大旗帜后人物变少 | 旗帜压住人物 | 旗帜退外侧，禁止进轮廓区 |

## 参考风格基调（贴合银丝古建）
- 人物：铸铜/青铜质感，暖面光打亮肌理
- 建筑：银丝浮雕、三角山墙、牌匾、蓝白旗阵，冷白灯光
- 整体：夜景氛围，灯光冷暖对比，人物暖、建筑冷
- 保留：街道车辆、两侧商铺、原图主体结构不动
