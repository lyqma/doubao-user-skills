## 一、对象选择模式（SCR 脚本中所有选择操作的基础）

| 模式 | SCR 写法 | 说明 |
|------|---------|------|
| 窗口选择 | `W` | 从左到右拖矩形，仅选完全在框内的对象 |
| 交叉选择 | `C` | 从右到左拖矩形，选框内及交叉的对象 |
| 栏栅选择 | `F` | 用折线跨越对象，选中被跨越的 |
| 上一组 | `P` | 选中上一次选择集 |
| 全部 | `A` | 选中图中所有对象 |
| 最后 | `L` | 选中最后创建的对象 |
| 窗围 | `WP` | 多边形窗口（闭合），仅选内部 |
| 窗交 | `CP` | 多边形交叉，选内部及穿越的 |
| 删除子集 | `-R` + 对象 | 从已有选择集中移除对象 |

**SCR 中的标准选择序列：**
```
命令: SELECT
选择对象: C ; 交叉选择
指定对角点: 1000,1000,0
找到 X 个 ...
```

## 二、高级修改命令（快手上层效率核心）

### 2.1 JOIN 与 PRESSPULL（拓扑修复神器）

```
; 将多条LINE/ARC合并为一条PLINE
COMMAND JOIN
选择源对象: C
选择对角点: 2000,2000,0    ; 框选所有相关线段
找到 N 个
选择要合并的对象:             ; 按 Enter 完成
结果: 合并为 1 条多段线
```

```
; PRESSPULL：在封闭区域内推拉，自动创建面域/实体
COMMAND PRESSPULL
点击要创建面的区域:           ; 点击台基轮廓内部
输入拉伸高度或 [路径(P)]: 400
结果: 生成一个体量为台基的实体
```

; 布尔并集

选择源对象: C                  ; 选多个面域/实体

; 布尔差集（挖孔）
COMMAND SUBTRACT

## 四、标注与文字（精确出图核心）

### 4.1 DIMSTYLE 标注样式管理器

```
; 创建古建专用标注样式
COMMAND DIMSTYLE
[管理器] → 新建 → 名称: "古建CAD-1:100"
→ 继续:
  ① 线条标签: 尺寸线颜色=7, 标记=建筑标记, 箭头大小=2.5
  ② 符号标签: 圆心标记=无, 弧长符号=无
  ③ 文字标签: 文字样式="古建标注", 高度=2.5, 颜色=7
  ④ 主要标签: 主单位精度=0, 换算单位精度=1
  ⑤ 调整标签: 标注特征比例=100（对应1:100图纸）
→ 置为当前 → 关闭
```

### 4.2 DIMOVERRIDE 临时覆盖

```
; 在不改变样式的前提下临时修改标注

输入新图层名 [?]: DIM_CUSTOM
```

### 4.3 多重引线 MLEADER

### 4.4 表格 TABLE
