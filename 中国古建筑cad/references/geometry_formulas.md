# 清式建筑比例公式全集

## 基础参数定义

| 符号 | 名称 | 单位 | 说明 |
|------|------|------|------|
| B | 对边距（六角）/ 面阔（殿） | mm | 主要控制参数 |
| W | 相邻柱中心距（六角） | mm | W = B / √3 |
| H_col | 檐柱高度 | mm | 从台基顶面到檐枋底面 |
| D_col | 檐柱直径 | mm | |
| eave | 檐出挑（出檐） | mm | 柱边至檐口的水平距离 |
| h_roof | 屋面举高（正脊至檐口垂直高差） | mm | |
| S | 斗口（面阔方向标准化模数） | mm | 清式基本模数 |

---

## 一、亭类（攒尖顶）

### 1.1 六角攒尖亭（清式）

```
W           = B / √3            ≈ B / 1.732
H_col       = B × 0.75          （檐柱高为对边距的 3/4）
D_col       = H_col × 0.085     （柱径约柱高的 8.5%，清式"柱径七分法"近似）
eave        = B × 0.32          （出檐约为对边距的 32%）
h_roof      = B × 0.40          （屋顶高度约为对边距的 40%）
H_plinth    = B × 0.133         （台基高约 400mm，按 B=3000 取常值）
R_base      = B × 0.6 × 1.2     （台基外半径，含台阶）
Kau_height  = H_col × 0.40      （美人靠高度）
```

**约束：**
- B ∈ [2000, 6000] mm
- H_col ∈ [1500, 4000] mm
- 超出范围时启用 fallback

### 1.2 八角攒尖亭（清式）

```
S_side      = B / 2.613         （每面边长，B 为对边距）
W           = B / 2.613         （柱间距等于边长）
H_col       = B × 0.75
D_col       = H_col × 0.085
eave        = B × 0.30
h_roof      = B × 0.38
H_plinth    = B × 0.133
R_base      = B × 0.6 × 1.2
Kau_height  = H_col × 0.40
```

## 二、殿类（歇山、庑殿）

### 2.1 单檐歇山殿（清式）

```
K           = B / 10            （斗口，B 为总面阔，mm；单檐殿通常取 B≈总宽×0.8）
H_col_front = B × 0.58          （前檐柱高，约面阔总宽的 58%）
H_col_back  = B × 0.52          （后檐柱高，约面阔总宽的 52%）
D_col       = H_col × 0.10      （柱径约为柱高的 10%）
D_pillar_inner = K × 2.0        （金柱直径）

出檐（当心间）:
  eave_front = B × 0.28         （前出檐约面阔的 28%）
  eave_back  = B × 0.18         （后出檐约面阔的 18%）

屋面举折：
  h_roof_front = B × 0.55       （屋面举高，约面阔的 55%）
  rise_ratio   = 0.35           （举高/跨度比，清式"举高三分五厘"）

台基：
  H_plinth   = B × 0.10         （台基高度，约面阔的 10%）
  W_plinth   = B + K × 16       （台基宽度，每边出 8 斗口）
  L_plinth   = D_depth × 1.4    （台基长度，进深方向）
```

### 2.2 双檐庑殿殿（清式）

```
K           = B / 10
H_col_low  = K × 16            （下层柱高）
H_col_high = K × 20            （上层柱高）
D_col      = K × 2.5
eave_low   = K × 7             （下层出檐）
eave_high  = K × 5             （上层出檐）
h_roof_low = K × 18            （下层屋顶举高）
h_roof_high= K × 25            （上层屋顶举高）
```

## 三、廊类

### 3.1 单面廊（清式）

```
span        = B               （廊面阔，单面）
H_col       = B × 0.65
D_col       = H_col × 0.09
eave        = B × 0.25
roof_rise   = B × 0.20        （硬山或悬山，坡度较缓）
col_spacing = B               （柱间距，等于面阔）
```

### 3.2 抄手游廊（清式）

```
走廊宽     = B × 0.30        （游廊净宽）
H_col      = B × 0.60
D_col      = H_col × 0.09
转角处     = 45° 斜廊过渡
```

---

## 四、坊类（牌楼/牌坊）

### 4.1 单间石牌坊（清式）

```
B           = 坊面阔（总宽）
H_total     = B × 1.8         （总高，含宝顶）
H_col       = B × 0.70        （柱高）
D_col       = B × 0.12        （石柱较粗）
eave        = B × 0.20        （牌坊出檐较小）
roof_type   = 盝顶 or 歇山顶
decor_level = 按等级配置
```

## 五、通用构件尺寸推导

### 5.1 梁枋截面

```
梁高        = 柱径 × 1.2 ~ 1.5
梁宽        = 柱径 × 0.8 ~ 1.0
枋高        = 柱径 × 0.6
枋宽        = 柱径 × 0.7
```

### 5.2 斗拱（清式单翘单才拱）

```
斗口 K      = 基本模数（见各建筑类型）
拱长度      = K × n            （n = 1~5 踩，依出跳数）
翘长度      = K × 2.0
昂长度      = K × 3.0
斗口宽      = K
耍头        = K × 0.8（高）× K × 2.0（长）
```

### 5.3 屋顶曲面（反曲线起翘）

清式屋顶采用"举折"做法，从正脊到檐口逐段降低坡度：

```
正脊高度   = 檐口标高 + h_roof
檐口起翘   = eave × 0.08        （出檐端部微上翘）
垂脊数量   = 根据屋顶类型确定
  - 攒尖顶：等于边数（六/八）
  - 歇山顶：正脊 1 条 + 垂脊 4 条 + 戗脊 4 条
  - 庑殿顶：正脊 1 条 + 垂脊 4 条 + 戗脊 4 条
```

### 5.4 栏杆（美人靠）

```
栏杆高     = H_col × 0.40
柱间距     = B_side × 0.8      （沿檐口布置）
栏板厚度   = 40 mm
望柱直径   = 60 mm
```

## 六、比例速查表（清式）

| 参数 | 亭（六角） | 殿（歇山） | 廊（单面） | 坊（单间） |
|------|-----------|-----------|-----------|-----------|
| H_col / B | 0.75 | K×20（K=B/10） | 0.65 | 0.70 |
| D_col / H_col | 0.085 | K×2.5 | 0.09 | 0.12 |
| eave / B | 0.32 | K×8 | 0.25 | 0.20 |
| h_roof / B | 0.40 | K×25 | 0.20 | — |
| H_plinth / B | 0.133 | K×6 | — | — |

> **注：** B 在亭类中为对边距，在殿类中为总面阔（间数×柱距）

## 五、坊类（牌楼/牌坊）

### 5.1 基本参数

```
W           = 总面阔（mm）
K           = W / 10          （斗口模数）
bays        = 间数（1/3/5）
depth       = 进深（通常 1~3 架）
```

### 5.2 单间石牌坊

```
H_col       = W × 0.75        （柱高约为面阔的 3/4）
D_col       = H_col × 0.10    （柱径约为柱高的 10%）
eave        = W × 0.25        （出檐）
h_roof      = W × 0.55        （屋顶举高）
H_plinth    = W × 0.12        （台基高）
top_decor   = W × 0.08        （宝顶/螭首高）
depth       = W × 0.50        （进深）
```

### 5.3 三间石牌坊

```
W           = 总面阔（mm）
K           = W / 10
H_col       = W × 0.55        （柱高约为总面阔的 55%）
D_col       = H_col × 0.10
eave        = W × 0.22        （出檐，比单间略小比例）
h_roof      = W × 0.60        （屋顶举高，三间更高）
H_plinth    = W × 0.10
top_decor   = W × 0.06
depth       = W × 0.20        （进深较浅）

明间比例：
  W_ming    = W × 0.45
次间比例：
  W_ci      = (W - W_ming) / 2
```

### 5.4 冲天柱式（柱顶高出屋面）

```
额外高度（柱顶高出屋面部分）:
  top_extra = H_col × 0.30~0.40
总高 = H_col + eave + h_roof + top_extra + top_decor
```

### 5.5 双檐木牌楼

```
H_col_lower = W × 0.45        （下层柱）
H_col_upper = W × 0.60        （上层柱）
eave_lower  = W × 0.25
eave_upper  = W × 0.18
h_roof_lower= W × 0.35
h_roof_upper= W × 0.45
H_plinth    = W × 0.10
```

### 5.6 牌楼与殿类的区别

| 对比项 | 牌楼 | 殿 |
|--------|------|-----|
| 功能 | 标识纪念，无内部空间 | 祭祀议事，有围合空间 |
| 墙体 | 通常无墙，仅柱网 | 有墙或半墙 |
| 屋顶 | 歇山为主，可重檐 | 歇山、庑殿、悬山 |
| 进深 | 浅（1~3架） | 深（3~9架） |
| 斗拱 | 显著，装饰性强 | 结构性为主 |
