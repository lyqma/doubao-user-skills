# 中国古建筑 CAD 制图规范 V4.12

## 一、图层命名规范

### 1.1 标准图层体系

| 图层名 | 颜色 | 线型 | 线宽建议 | 用途 |
|--------|------|------|---------|------|
| AXIS | 1(红) | CENTER | 0.25mm | 定位轴线 |
| AXIS_AUX | 1(红) | CENTER | 0.18mm | 辅助轴线 |
| BASE | 8(白) | CONTINUOUS | 0.50mm | 台基、台阶、须弥座 |
| WOOD_FRAME | 3(绿) | CONTINUOUS | 0.35mm | 柱、梁、枋、檩、椽 |
| DOUGONG | 6(青莲) | CONTINUOUS | 0.25mm | 斗拱层 |
| ROOF | 5(青) | CONTINUOUS | 0.50mm | 屋面轮廓、脊件 |
| RAIL | 4(蓝) | CONTINUOUS | 0.25mm | 栏杆、美人靠、望柱 |
| DECO | 10(黄) | CONTINUOUS | 0.18mm | 装饰构件（匾额、螭首等） |
| WALL | 9(洋红) | CONTINUOUS | 0.35mm | 墙体（殿类用） |
| DIM | 2(白) | CONTINUOUS | 0.18mm | 尺寸标注 |
| ANNOTATION | 7(白) | CONTINUOUS | 0.25mm | 文字说明、标题 |
| HIDDEN | 1(红) | HIDDEN | 0.18mm | 不可见轮廓 |
| SECTION | 4(蓝) | CONTINUOUS | 0.50mm | 剖面填充区域 |
| FILL | 8(灰) | CONTINUOUS | 0.18mm | 剖面线/填充 |

### 1.2 图层创建语句（完整）

```
LAYER NEW AXIS COLOR 1 CENTER LINETYPE CENTER
LAYER NEW AXIS_AUX COLOR 1 CENTER LINETYPE CENTER
LAYER NEW BASE COLOR 8 CONTINUOUS
LAYER NEW WOOD_FRAME COLOR 3 CONTINUOUS
LAYER NEW DOUGONG COLOR 6 CONTINUOUS
LAYER NEW ROOF COLOR 5 CONTINUOUS
LAYER NEW RAIL COLOR 4 CONTINUOUS
LAYER NEW DECO COLOR 10 CONTINUOUS
LAYER NEW WALL COLOR 9 CONTINUOUS
LAYER NEW DIM COLOR 2 CONTINUOUS
LAYER NEW ANNOTATION COLOR 7 CONTINUOUS
LAYER NEW HIDDEN COLOR 1 HIDDEN LINETYPE HIDDEN
LAYER NEW SECTION COLOR 4 CONTINUOUS
LAYER NEW FILL COLOR 8 CONTINUOUS
```

## 二、图纸比例规范

### 2.1 常用比例

| 图纸类型 | 推荐比例 | 适用场景 |
|---------|---------|---------|
| 总平面图 | 1:500 / 1:1000 | 建筑群布局 |
| 平面图 | 1:100 / 1:50 | 单栋建筑平面 |
| 剖面图 | 1:50 / 1:30 | 关键剖面 |
| 立面图 | 1:50 / 1:30 | 正立面/侧立面 |
| 大样图 | 1:20 / 1:10 | 斗拱、檐口细节 |
| 节点详图 | 1:5 / 1:2 | 榫卯、构件连接 |

### 2.2 标注样式规范

| 参数 | 数值 | 说明 |
|------|------|------|
| 标注单位 | 毫米(mm) | 所有尺寸以mm为单位 |
| 文字高度 | 平面图: 2.5mm / 剖面: 3.0mm | 图纸比例为1:100时 |
| 尺寸线间距 | 7mm | 平行尺寸线间距 |
| 尺寸界线超出 | 2mm | 超出尺寸线长度 |
| 箭头类型 | 建筑标记(斜线) | 古建常用 |
| 公差标注 | 整数mm | 不标小数位 |

### 2.3 文字样式规范

| 参数 | 数值 | 说明 |
|------|------|------|
| 字体 | 宋体 / 仿宋 / SHX简宋 | 中文标注 |
| 标注文字高度 | H80 (图上80mm) | 1:100比例下实际800mm |
| 说明文字高度 | H60 | 参数注释 |
| 标题文字高度 | H120 | 图纸标题 |

## 三、线型规范

### 3.1 线宽体系

| 线宽组 | 宽度 | 用途 |
|--------|------|------|
| 粗线 | 0.5~0.7mm | 剖面轮廓、可见主要构件 |
| 中粗线 | 0.35mm | 柱、梁、台基轮廓 |
| 细线 | 0.18~0.25mm | 轴线、标注、文字 |

### 3.2 剖面线规范

```
; 石质材料（台基、柱础）
HATCH SOLID 0.18 45 ; 实心中灰色
; 木质材料（柱、梁）
HATCH ANSI31 0.25 45 ; 45度平行细线
; 砖墙
HATCH BRICK 0.25 0 ; 砖砌图案
; 混凝土
HATCH AR-CONC 0.25 0 ; 混凝土图案
```

## 四、图纸内容规范

### 4.1 平面图必备内容

```
1. 定位轴线（AXIS层，红色CENTER线）
2. 台基轮廓（BASE层，含台阶收分）
3. 柱网定位（WOOD_FRAME层，柱位圆圈）
4. 檐枋连线（WOOD_FRAME层）
5. 屋面轮廓（ROOF层，出檐投影）
6. 栏杆/美人靠（RAIL层，如有）
7. 尺寸标注（DIM层，面阔/进深/柱距）
8. 文字标注（ANNOTATION层，名称+参数）
```

### 4.2 剖面图必备内容

```
1. 地坪线（±0.000基准）
2. 台基台阶（含收分）
3. 柱（前/后，标注高度差）
4. 梁枋系统（檐枋→金枋→脊枋）
5. 斗拱层（full_detail模式）
6. 屋面轮廓（含脊件）
7. 宝顶/螭首
8. 尺寸标注（层高、总高）
```

### 4.3 立面图必备内容

```
1. 台基轮廓
2. 檐柱（标注柱径、柱高）
3. 额枋/檐枋
4. 斗拱层（如需）
5. 屋面轮廓（歇山/攒尖形制）
6. 正脊、垂脊、戗脊
7. 宝顶
8. 匾额位置标注
```

## 五、出图标注规范

### 5.1 平面图标注

```
; 必标尺寸
1. 总面阔/总进深（外轮廓）
2. 柱间距（各开间）
3. 柱径
4. 出檐宽度
5. 台基尺寸

; 必标文字
1. 建筑名称
2. 主要参数（B/W/H等）
3. 比例标注
```

### 5.2 剖面图标注

```
; 必标尺寸
1. 台基高度
2. 各层柱高
3. 檐口标高
4. 正脊标高
5. 总高度

; 必标文字
1. 剖切位置说明
2. 构件名称标注
3. 比例
```

## 七、常见错误与规避

| 错误 | 后果 | 规避方法 |
|------|------|---------|
| 相对坐标混用 | 图形偏移 | SCR只用绝对坐标 |
| 图层未创建直接用 | 命令报错 | 先LAYER NEW再使用 |
| 坐标顺序错误 | 图形颠倒 | 统一X=面阔,Y=进深,Z=标高 |
| 比例尺不统一 | 打印尺寸错误 | 全程mm单位，图纸比例单独标注 |
| 线型未加载 | CENTER/HIDDEN显示为实线 | 在CAD中先LOAD线型 |
| 中文字体显示乱码 | 标注不可读 | 使用SHX简宋体或正确中文环境 |
