# 牌楼（牌坊）类型数据库 V4.12

## 概述

牌楼是中国传统纪念性建筑，建于道路、桥梁、宫殿、陵墓入口处，起标识和装饰作用。
无内部使用空间，核心特征：**柱网支撑 + 多层檐顶 + 匾额题字**。

---

## 一、按间数分类

| 名称 | 间数 | 总面阔范围 | 典型场景 | 等级 |
|------|------|-----------|---------|------|
| 单间牌坊 | 1 | 3000~5000mm | 园林入口、小型纪念门 | 低 |
| 三间牌坊 | 3 | 9000~15000mm | 孔庙、陵墓、祠堂入口 | 中 |
| 五间牌坊 | 5 | 18000~25000mm | 帝王陵寝、大型坛庙 | 高 |

## 二、按柱式分类

### 2.1 屋盖式（有宇式）
- 柱顶不超出屋面，外观规整
- 常见于民间牌楼
- 构造：柱→额枋→桁檩→屋面

### 2.2 冲天式（柱出头）
- 柱顶高出屋面，柱头做花斑或云纹
- 气势挺拔，视觉上更雄伟
- 常见于陵墓、祠庙

## 四、清式牌楼比例体系

### 4.1 基本模数 K（斗口）

```
K = 总面阔 W / 10       （常用，中等规模）
K = 总面阔 W / 12       （小规模，柱细）
K = 总面阔 W / 8        （大规模，柱粗壮）
```

### 4.2 单间石牌坊（清式）

```
K            = W / 10
H_col        = K × 18           （柱高，约面阔的 1.8 倍）
D_col        = K × 2.5          （柱径）
eave         = K × 7            （出檐）
h_roof       = K × 20           （屋顶举高）
H_plinth     = K × 5            （台基高）
top_decor    = K × 3            （宝顶/螭首高度）
W_sub        = W × 0.35         （次间面阔，单间无次间）
```

### 4.3 三间石牌坊（清式）

```
W            = 明间 + 次间×2
K            = W / 10
H_col        = K × 18
D_col        = K × 2.5
eave         = K × 7
h_roof       = K × 22
H_plinth     = K × 5
top_decor    = K × 3

明间比例：
  W_ming     ≈ W × 0.45         （明间略宽）
次间比例：
  W_ci       = (W - W_ming) / 2
柱位分布：
  前檐柱：5根（明间2根 + 次间各1根 + 两侧边柱1根）
  后檐柱：同上（纵深方向）
```

### 4.4 五间木牌楼（清式）

```
K            = W / 10
H_col_low    = K × 16           （下层柱）
H_col_high   = K × 20           （上层柱）
D_col        = K × 2.5
eave_low     = K × 7
eave_high    = K × 5
h_roof_low   = K × 18
h_roof_high  = K × 25
H_plinth     = K × 5
top_decor    = K × 4
```

## 五、牌楼平面布局

### 5.1 单间平面

```
      ←─── W ───→
      
    ╔═══════════════╗
    ║    匾额区     ║  ← 屋顶（歇山或盝顶）
    ╠═══════════════╣
    ║  ┌─────┐  ┌─────┐ ║  ← 额枋 + 斗拱层
    ║  │     │  │     │ ║
    ║  │柱   │  │柱   │ ║  ← 两根檐柱
    ║  │     │  │     │ ║
    ║  └─────┘  └─────┘ ║
    ╚═══════════════╝
    
    进深：通常 1 架 = K × 4 ~ K × 6（约 1500~3000mm）
```

### 5.2 三间平面

```
          明间              次间    次间
      ←──── W_ming ────→←──W_ci──→←──W_ci──→
    
    ╔════════════════════════════════════════╗
    ║           屋顶（三重檐歇山）            ║
    ╠════════════════════════════════════════╣
    ║  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ║
    ║  │柱│  │柱│  │柱│  │柱│  │柱│  │柱│  ║  ← 6根檐柱（前后各3根）
    ║  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  ║
    ╚════════════════════════════════════════╝
    
    进深：2~3 架
    柱网：明间 2 柱，次间各 1 柱
```

### 5.3 四柱三间冲天式

```
    明间                  次间    次间
←────── W_ming ──────→←──W_ci──→←──W_ci──→

     ↑ 冲天柱 ↑        ↑ 冲天柱 ↑
     │          │      │          │
    ┌┴──────────┴┐    ┌┴──────────┴┐
    │   明间檐口  │    │   次间檐口  │
    │   匾额"忠"  │    │   匾额"孝"  │
    └────────────┘    └────────────┘
    
    特点：柱顶穿出屋面，做花斑装饰
```

## 六、牌楼立面构件

### 6.1 竖向分层（从下到上）

```
┌─────────────────────────────────────┐
│  宝顶 / 螭首 / 云板                │ ← top_decor (K×3~4)
├─────────────────────────────────────┤
│  正脊 + 垂脊 + 戗脊                │ ← roof
├─────────────────────────────────────┤
│  次层檐（如有）                     │ ← upper eave
├─────────────────────────────────────┤
│  主层檐 + 斗拱                     │ ← main eave + Dougong
├─────────────────────────────────────┤
│  额枋 + 匾额                       │ ← 枋 + 匾
├─────────────────────────────────────┤
│  檐柱（含础石）                     │ ← columns
├─────────────────────────────────────┤
│  台基 + 台阶                        │ ← plinth
└─────────────────────────────────────┘
```

### 6.2 斗拱层（清式牌楼常用）

| 构件 | 位置 | 尺寸参考 |
|------|------|---------|
| 栌斗 | 柱头 | K×2 宽 × K×1.5 高 |
| 交互斗 | 拱端 | K×1.5 宽 × K×1 高 |
| 泥道拱 | 斗间 | 长 K×5，高 K×1 |
| 耍头 | 最外 | 长 K×4，高 K×2 |
| 翘 | 横向出跳 | 长 K×2，截面 K×K |

## 八、牌楼图纸规范

### 8.1 图层新增

```
DECO       — 装饰构件（黄）   匾额、花斑、云板
DOUGONG    — 斗拱层（青莲）   栌斗、拱、翘
```

### 8.2 标注要点

- 总面阔 W
- 明间面阔 W_ming
- 柱高 H_col
- 檐高（地面至檐口）
- 总高（地面至宝顶）
- 柱间距（开间尺寸）
- 斗拱出跳数

## 九、JSON 配置字段（牌楼专用）

```json
{
  "id": "paifang_3bay_stone",
  "name": "清式三间石牌坊",
  "category": "坊",
  "subtype": "三间石牌楼",
  "W": 10800,
  "bays": 3,
  "bay_spacing": [3600, 3600, 3600],
  "depth": 2400,
  "column_style": "straight",
  "roof_type": "xieshan",
  "material": "stone"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `W` | 数字 | 总面阔 mm |
| `bays` | 数字 | 间数（1/3/5） |
| `bay_spacing` | 数组 | 各间开间尺寸数组 |
| `depth` | 数字 | 进深 mm |
| `column_style` | 字符串 | `straight`(屋盖式) / `chongtian`(冲天式) |
| `roof_type` | 字符串 | `xieshan`(歇山) / `luding`(盝顶) / `xuanshan`(悬山) |
| `material` | 字符串 | `stone`(石) / `wood`(木) / `brick`(砖石) |
