# 抖音视频自动发布技能

- 来源：LobeHub christophacham/agent-skills-library（参考 social-auto-upload 实现）
- 适配环境：本机浏览器自动化（computer_use_tool plane="bu"）

## 使用场景

- 用户需要发布视频到抖音时
- 用户说 "发抖音"、"上传抖音"、"发布到抖音" 时
- 用户有视频文件需要分发到抖音平台时

## 技术原理

基于浏览器自动化模拟真实用户操作抖音创作者中心（https://creator.douyin.com）：

1. 首次使用需扫码登录，保存登录态
2. 后续使用自动登录
3. 自动化填充标题、话题、封面等信息
4. 支持定时发布

## 前置条件

1. 视频文件要求：
   - 格式：`.mp4`（推荐）
   - 分辨率：建议 1080x1920（竖版 9:16）
   - 文件大小：建议不超过 4GB
   - 可选：同名的封面图片（`.png` 或 `.jpg`）

2. 登录态：首次运行需在创作者中心完成扫码登录（本环境已登录 HNXXHJKCZ）

## 工作流程

### 第一步：确认登录状态
检查浏览器创作者中心登录态是否有效（导航到 creator.douyin.com 看是否显示账号）；失效则重新扫码登录。

### 第二步：准备视频文件
- MP4、1080×1920 竖版、≤4GB
- 可选同名校封面图

### 第三步：发布视频

```
python scripts/publish.py \
  --video "视频文件路径" \
  --title "视频标题" \
  --tags "话题1,话题2,话题3" \
  [--cover "封面图片路径"] \
  [--schedule "2025-01-31 18:00"]
```

#### 参数说明

| 参数 | 简写 | 说明 | 必填 |
|---|---|---|---|
| `--video` | `-v` | 视频文件路径 | ✅ |
| `--title` | `-t` | 视频标题（最多 30 字） | ✅ |
| `--tags` | `-g` | 话题标签，逗号分隔 | ❌ |
| `--cover` | `-c` | 封面图片路径 | ❌ |
| `--schedule` | `-s` | 定时发布时间（YYYY-MM-DD HH:MM） | ❌ |
| `--headless` | | 无头模式运行 | ❌ |

#### 使用示例

```
# 立即发布
publish.py -v /path/demo.mp4 -t "今天学到一个超实用的技巧" -g "干货分享,效率提升,学习"

# 定时发布 + 指定封面
publish.py -v /path/demo.mp4 -t "周末vlog｜一个人的惬意时光" -g "vlog,周末日常" -c cover.png -s "2025-02-01 18:00"

# 无头模式（后台运行）
publish.py -v /path/demo.mp4 -t "测试视频" --headless
```

### 本环境执行路径（不使用 Python/Playwright，用内置浏览器自动化）

1. 导航到发布页：`creator.douyin.com/creator-micro/content/upload`（商单任务走任务详情页"上传视频"，URL带order_id）
2. `bu.upload_file('input[type=file]', video_path)` 上传
3. 等待跳转到 `post/video` 发布页
4. `bu.fill_input('input[placeholder*="标题"]', title)` 填标题
5. 正文用 Clipboard API 粘贴（富文本编辑器）
6. 话题：# 加入正文或话题输入框
7. 确认封面（AI 推荐或选关键帧）
8. 点发布（商单任务组件自动挂载；发布为对外操作，用户确认后执行）


## 注意事项

1. **登录态有效期**：长时间未使用或平台更新可能需要重新登录
2. **发布频率**：建议控制发布频率，避免被平台识别为异常行为（每号每日 3-5 条为宜）
3. **标题限制**：抖音标题最多 30 字（商单任务另行要求），超出自动截断
4. **话题数量**：建议 3-5 个相关话题，提高曝光
5. **封面选择**：不指定封面则系统自动从视频中选取推荐封面
6. **定时发布**：发布时间需在当前时间之后，且在平台允许范围内

## 常见问题

| 问题 | 解决 |
|---|---|
| 登录失效 | 重新扫码登录 |
| 上传失败 | 检查网络、视频格式（MP4），看错误信息 |
| 批量发布 | 循环调用 publish.py，每次间隔几分钟 |
| 商单任务投稿 | 走任务详情页"上传视频"入口，任务组件自动挂载，勿用普通发布入口 |

## 发布成功后素材清理（强制规则）

**规则：只要视频发布成功（抖音侧显示"已发布"或"审核通过"），必须立即删除本地原素材，不得留存。**

### 删除范围

1. 任务方提供的原素材（百度网盘等下载的剧集片段、素材包、参考图）
2. 剪辑中间产物（剪辑工程、分段片段、临时渲染文件）
3. 成片 MP4（投稿完成后不再保留）

### 执行方式

- Windows：`Remove-Item -Path <文件路径> -Force`
- 删除前先记录文件清单（路径 + 大小），便于核对
- 删除后确认文件已不存在，再向用户汇报"素材已清理"

### 目的

- 版权合规：商单素材仅授权用于该任务投稿，禁止留存、二次使用或转售
- 账号安全：防止误用未授权素材发布其他内容导致限流/封号

### 例外

- 仅当用户**明确主动要求**保留素材时，才不删除。
